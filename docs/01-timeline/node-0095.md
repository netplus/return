# NODE-0095：终极卧底、大道玉衣与青木城双向伏击

- **章节范围：** 第 716—722 章
- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

徐霄在青木城前线继续利用“人族百万年终极卧底”叙事，释放陈大浩神魂并取得其保密承诺。与此同时，他向青曼赠送九霄玉舟，返还九天青木舟；又向玄雪等人配置高阶仙器，获得大道玉衣及五行道器剑阵相关资源。

天玄仙宗与孔青分别派出人族、妖族天地玄仙伏击徐霄。两支暗杀队伍在同一区域形成前后夹击。徐霄以大道玉衣防御，并首次公开施展由大道玄冰剑、大道天金剑、大道天木剑、大道天火剑和大道神土剑组成的五行道器剑阵，击杀大部分伏击者。

徐霄在最后阶段识别诸葛绫为 SS 级气运之女并停止追杀。周紫薇赶到后继续相信其人族卧底身份，与徐霄正式确立关系，并协助诸葛绫隐瞒战斗真相。徐霄随后返回青木城，将妖族伏击者之死包装为人族强者所为，完成双向身份掩护。

## 关键因果链

1. 徐霄释放陈大浩神魂并强化卧底叙事 → 天玄仙宗内部形成错误但持续有效的身份认知。
2. 孔青与天玄仙宗分别部署暗杀队 → 人妖两侧敌对力量在同一战场夹击徐霄。
3. 大道玉衣与五行道器剑阵首次实战 → 徐霄战力正式达到至尊玄仙威慑层级。
4. 诸葛绫被系统识别为 SS 级对象 → 徐霄停止击杀并转为关系与保密处理。
5. 周紫薇接受卧底叙事并确立关系 → 天玄仙宗内部形成新的保密通道。
6. 第 722 章返回青木城并完成战果叙事 → 第 723 章转入韵幽关系与造化滴血重生。

- **徐霄：** 获得九天青木舟、大道玉衣与五行道器剑阵；公开展示至尊玄仙级战力；与周紫薇正式确立关系。
- **周紫薇：** 由获救与赠丹对象转为徐霄伴侣，并主动承担卧底身份保密。
- **诸葛绫：** 天玄仙宗天地玄仙、SS 级气运之女；重伤后被徐霄放过并参与保密。
- **孔青：** 暗派五名妖族天地玄仙截杀徐霄，计划失败且亲信全部死亡。

- **玄雪：** 获得通天如意针等高阶资源，玄鸟族资源绑定继续加强。
