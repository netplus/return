# NODE-0071：外门长老问罪、资源拜师与矿区离场

- **章节范围：** 第 537—544 章
- **粒度：** Story arc
- **核验状态：** `partial`

## 剧情摘要

阴阳仙门外门长老团因徐霄与韩烟的公开关系集中前往六号矿坑问罪。西门恨天领衔的制裁团试图将徐霄、李香香分开处置；徐霄取出人仙巅峰神霄仙火符后，外门首席执法长老云鹤迅速终止强制处置，现场关系由单方面制裁转为平等谈判。

韩烟推动徐霄拜入大师姐柳清浅门下。柳清浅最初拒绝，但徐霄以十枚化仙丹和一枚人仙巅峰魂丹作为拜师礼，最终完成师徒关系。南宫嫣则选中李香香为徒，并接受徐霄用于照顾李香香的十枚化仙丹。徐霄在离开矿区前向邹蒙、陈念及一四六号矿队成员赠送雷灵丹，完成矿区关系与资源交代。

一个半月后，司空浩南组织数十名外门弟子伏击徐霄。徐霄以山河灵图在极短时间内收纳全部伏击者，并在灵图小世界中完成清剿。第544章末，徐霄抵达阴阳仙门外门；第545章开始转入宗门弟子舆论与内部冲突。

## 关键因果链

1. 韩烟关系消息传入外门 → 三四十名外门长老集中前往矿区问罪。
2. 西门恨天要求处置徐霄与李香香 → 徐霄展示人仙巅峰神霄仙火符。
3. 顶级符箓形成现实威慑 → 云鹤终止制裁并推动长老团道歉降级。
4. 韩烟引荐柳清浅 → 徐霄以高阶丹药和魂丹完成拜师。
5. 南宫嫣选中李香香 → 李香香获得外门长老师承并与徐霄一同离开矿区。
6. 徐霄完成矿区赠礼交代 → 一四六号矿队关系转为长期资源人脉。
7. 司空浩南发动伏击 → 山河灵图完成收纳和清剿，矿区敌对主线结束。
