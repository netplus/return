## 剧情摘要

纯阳仙门追捕队在铁钩狱围杀徐霄。徐霄先以人仙九重肉身压制地仙巅峰金华，随后动用神御黑冰符，将吕玄一、金华、萧天及七名天仙长老一并冻结击杀。系统据此完成三项返还库升级：阵法符箓上限提升至玄仙，丹药上限提升至玄仙，法器上限提升至道器。

进入后续狱层后，徐霄向青鸾赠送十颗五行仙丹。首次赠送触发万倍暴击返还万佛金身丹，余下九颗返还九十颗玄元仙丹。天一仙门大长老独孤惊云依靠道天仙体、天仙六重修为和至尊仙剑阻拦诸宗，徐霄以圆满剑之大道及冰火双至尊仙剑正面对抗，确认自身已具至尊之下顶级战力。

追捕队进入阿鼻地狱后，徐霄以雷遁超越各宗遁术，率先抵达金殿并控制邬秋。佛门僧人忌口将徐霄认定为邬秋的“有缘人”，邬秋主动交出储物袋。徐霄取出地脉岩火剑交给东方青，并推动将邬秋带出小世界公开审理。第658章众人返回铁钩狱并离开无间地狱；第659章转入徐霄在外部公开保下邬秋的新冲突。

## 关键因果链

1. 纯阳仙门集体围杀徐霄 → 徐霄使用神御黑冰符完成十人清除。
2. 吕玄一、金华、萧天三个系统目标被击杀 → 阵法符箓、丹药、法器三类返还库分别升级。
3. 青鸾接受十颗五行仙丹 → 获得万佛金身丹与九十颗玄元仙丹返还。
4. 独孤惊云布阵阻拦 → 徐霄公开展示圆满剑道和双至尊仙剑战力。
5. 徐霄以雷遁率先抵达阿鼻地狱 → 控制邬秋并取得地脉岩火剑。
6. 邬秋被带出无间地狱 → 追捕目标由内部争夺转为外部处置与保人冲突。
