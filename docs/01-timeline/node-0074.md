- **核验状态：** `partial`

## 剧情摘要

道侣大会结束后，徐霄的六甲双金名声传入阴阳仙门内门。凤青玄和以“刘爱花”身份活动的姬雪先后确认徐霄已经飞升。凤青玄已拜入青鸾长老门下并晋升人仙二重；姬雪则拜入瑶光长老门下，晋升人仙三重。

徐霄继续向旧识和师门配置仙界资源。柳清浅接受十枚化仙丹和顶级仙器九霄玄冰剑，徐霄承诺即使转拜掌门后仍持续承担其修炼资源。凤青玄与徐霄重逢后接受十枚化仙丹、人仙巅峰魂丹和九霄神焰剑；系统分别返还一百枚仙元丹、一枚天仙巅峰魂丹和至尊神火剑。凤青玄暂未正式确认道侣，但接受长期资源支持。

外门大长老罗素主动到访。她确认与东方青的道侣关系早已终止，并与徐霄建立公开亲密关系。相关赠送返还包括天仙顶级神御黑冰符，以及十枚仙元丹返还十枚天仙境五行仙丹。徐霄的仙界资源网络由外门弟子和外门长老，进一步扩展至内门弟子与外门大长老层级。

## 关键因果链

1. 六甲双金名声传入内门 → 凤青玄、姬雪确认徐霄飞升并进入重逢线。
2. 柳清浅资源消耗加快 → 徐霄继续提供丹药并赠送九霄玄冰剑，师徒资源关系长期化。
3. 凤青玄接受复合高阶赠礼 → 系统返还仙元丹、天仙魂丹和至尊神火剑。
4. 罗素主动到访并确认单身状态 → 徐霄与罗素建立公开关系。
5. 罗素接受高阶资源 → 系统返还神御黑冰符与五行仙丹。
6. 第 573 章南宫嫣道伤和府邸冲突成为中心 → 结束本节点。
