## 剧情摘要

林嫣儿相关赠礼在外门传播后，大量弟子主动前往徐霄住处帮忙。徐霄从中识别出新的 C 级气运之女金柳香，并在众人离开后向她赠送十枚筑基丹。金柳香接受赠礼后，其首次有效赠送触发百倍暴击，系统返还一枚可增加三百年寿元的绝品寿元丹。

金柳香将徐霄的资源支持理解为建立长期亲密关系的邀请。她本为周啸弟子，修为筑基二重，但决定主动接近徐霄并提出长期照料。双方关系加深后，系统显示羁绊度由 1 提升至 2，基础返还倍率由十倍提高至二十倍。徐霄随后赠出中品碧玉金钗、下品防御法戒和十枚上品灵石：碧玉金钗在羁绊升级后的首次赠送中触发千倍暴击，返还绝品法器四海升平坠；其余两项分别返还两枚中品法戒和二百枚上品灵石。

一个月后，徐霄以高额资源帮助外门女弟子的传闻已经在宗门外门固化。陆大年选择压制恶意议论，并以师门照料和寻找道侣的安排解释徐霄的行为。第 17 章转入周啸针对金柳香与徐霄关系的算计，形成新的正面冲突，因此本节点在第 16 章结束。

## 关键因果链

1. 林嫣儿事件扩大徐霄在外门的影响力，引来更多弟子主动接近。
2. 徐霄识别金柳香为 C 级气运之女，并以筑基资源建立自然、有效的赠送关系。
3. 金柳香首次接受十枚筑基丹，触发百倍暴击，返还绝品寿元丹。
4. 金柳香主动提出长期照料，双方关系加深，羁绊度由 1 提升至 2。
5. 羁绊提升使基础返还倍率由十倍提高至二十倍。
6. 羁绊升级后的首次赠送再次触发千倍暴击，返还四海升平坠。
7. 一个月的持续互动使关系和宗门舆论稳定化，同时引出周啸的敌意与下一阶段冲突。

## 主要状态变化

- 徐霄：修为由筑基四重恢复至筑基五重；获得绝品寿元丹和四海升平坠；上品灵石资源显著增加。
- 金柳香：首次登场；缥缈宗外门弟子、周啸弟子；筑基二重；C 级气运之女；与徐霄羁绊度由 1 提升至 2。
- 陆大年：继续维护徐霄在外门的声誉，并压制恶意传播。
- 外门环境：徐霄赠送资源和寻找伴侣的传闻成为持续性公共议题。

## 系统与物品增量

- 金柳香首次赠送：十枚筑基丹 → 百倍暴击 → 绝品寿元丹。
- 金柳香羁绊度：1 → 2。
- 金柳香基础倍率：十倍 → 二十倍。
- 羁绊升级后的首次赠送：中品碧玉金钗 → 千倍暴击 → 四海升平坠。
- 同批后续返还：下品防御法戒 → 两枚中品法戒；十枚上品灵石 → 二百枚上品灵石。
- 新确认规则：羁绊度提升可以提高基础返还倍率；羁绊等级首次提升后的赠送可再次触发暴击。后一项因部分章节依赖交叉来源，暂标记为 `partial`。
