# NODE-0099：诸葛青天孤注一掷、锁妖塔爆炸与鹤仙儿封口

- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

徐霄打穿锁妖塔后，诸葛青天因极端绝望启动系统最强燃烧模块，将最后万年寿元全部燃烧，仅留一天生命，修为跃升至玄仙巅峰，并以两柄道器神剑冲击锁妖塔十八层和金仙契机。徐霄预先留在十八层阵眼的玄仙顶级火符被触发，摧毁高层幻境并使诸葛青天肉身与神魂俱灭。锁妖塔十二层以上炸毁，龙九天以阵法年久失修作为公开结论，收走诸葛青天遗留的两柄道器神剑。

诸葛青天死亡完成气运之子击杀任务，系统将法器返还库上限提升至规则道器。鹤仙儿凭阵法感知察觉徐霄曾激活阵眼，以揭发相威胁；徐霄通过仙丹、至尊仙器和高阶丹药达成封口与长期资源协议。系统返还三千天道丹、金仙道丹、三件道器与金仙巅峰魂丹。徐霄服用三千天道丹后完美领悟幻象大道，玄雪羁绊度提升至二。第 752 章转入赤裳为赤澜儿再次上门问责的新阶段。

## 关键因果链

1. 徐霄锁妖塔纪录造成诸葛青天极端绝望 → 诸葛青天燃尽寿元并提升至玄仙巅峰。
2. 诸葛青天携两柄道器冲击十八层 → 获得金仙突破契机。
3. 徐霄预留的玄仙顶级火符被触发 → 诸葛青天魂飞魄散、锁妖塔上半部炸毁。
4. 诸葛青天死亡 → 徐霄完成气运之子击杀任务，法器返还库上限提升至规则道器。
5. 鹤仙儿察觉阵眼灵力波动 → 形成揭发风险。
6. 徐霄以高阶资源换取保密 → 鹤仙儿与其建立持续赠送关系。
7. 三千天道丹返还并被服用 → 徐霄完美领悟幻象大道。
8. 第 752 章赤裳到访 → 转入赤狐族问责与新一轮资源交换。

## 主要人物与状态变化

- **徐霄：** 秘密触发十八层火符，完成诸葛青天气运任务；法器返还上限提升至规则道器；完美领悟幻象大道；与鹤仙儿建立封口型长期资源关系。
- **诸葛青天：** 燃尽万年寿元，仅留一天生命，短暂达到玄仙巅峰并获得金仙契机；最终在锁妖塔爆炸中魂飞魄散。
- **鹤仙儿：** 察觉徐霄激活阵眼，以揭发相威胁，接受复合赠礼并承诺保密。
- **龙九天：** 将事故公开归因于幻阵年久失修，封闭锁妖塔并收走诸葛青天遗留道器。
- **天穹：** 原计划收诸葛青天为亲传弟子，因其陨落失去候选弟子。
- **独孤惊云：** 失去主要反徐盟友，长期敌对阵营进一步削弱。
- **玄雪：** 与徐霄羁绊度提升至二，关系进一步稳定。
- **凤溪：** 万妖仙宗大长老，主张将徐霄视为太乙仙潜力对象并纳入长期培养。
