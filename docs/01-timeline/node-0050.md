## 剧情摘要
铁焰城拍卖会开启前，徐霄首次确认青云仙宗掌门陆雪瑶为 SSS 级气运之女。陆雪瑶与玉冰同修冰系大道，是青山域顶级宗门掌门及长期被并列比较的绝代天才，但本阶段尚未与徐霄形成赠送结算。

拍卖会上，徐霄以明显高于常规价值的价格连续竞买法宝，并在压制法器竞拍中以资源优势买断九件可用名额。此举使无妄仙宗能够增派大乘修士进入阴煞界，也同时激化四域顶级宗门对徐霄的敌意。萧烬璃因灵宝和灵石收益私下邀请徐霄，双方关系由单纯资源接受转为带有长期利益交换的暧昧合作；萧家内部仍将其解释为利用徐霄资源。

铁焰城破界前，萧家将压制法器通过黑市重新提供给其他仙门，使各宗对徐霄的直接恨意有所下降，但萧家与徐霄的关系继续引发公开争议。铁焰城随后化为可跨界移动的天地法宝，整体进入阴煞界。系统确认魔姝为 C 级气运之女；魔姝是大乘六重修士、长眉太上长老重点照拂之人，并主动邀请徐霄加入队伍。第 388 章完成行动队伍组建，第 389 章转入阴煞界内部阴谋和正式探索。

## 关键因果链
1. 徐霄参加铁焰城拍卖会，首次确认陆雪瑶的 SSS 级气运身份。
2. 为强化无妄仙宗进入阴煞界的大乘阵容，徐霄高价竞拍并取得九件压制法器。
3. 买断行为损害其他顶级仙门的进入名额，四域宗门对徐霄的敌意集中爆发。
4. 萧烬璃因徐霄提供的灵宝与灵石资源主动私下邀请，双方形成资源利益驱动的持续接触。
5. 萧家随后通过黑市出售压制法器，使其他仙门仍能以较低代价进入阴煞界，也构成对徐霄竞拍策略的利益性背刺。
6. 铁焰城由萧家老祖操纵，化为小型天地法宝并穿越空间裂缝进入阴煞界。
7. 系统确认魔姝为 C 级气运之女；魔姝主动邀请徐霄组队，徐霄加入其队伍。
8. 第 388 章完成组队与行动安排；第 389 章开启阴煞界阴谋和正式资源探索。

## 主要状态变化
- 徐霄：以个人灵石取得九件压制法器，显著增强无妄仙宗阴煞界行动阵容；与萧烬璃形成持续利益和关系接触；加入魔姝带领的阴煞界队伍。
- 陆雪瑶：首次登场；青云仙宗掌门、SSS 级气运之女、冰系大道修士，当前对徐霄保持明显负面评价。
- 萧烬璃：由接受赠送资源进一步转为主动私下邀请徐霄，并继续以获取徐霄资源作为萧家利益策略。
- 玉冰：接收九件压制法器并承担无妄仙宗阴煞界队伍组织职责；对徐霄与萧烬璃的持续接触保持不满。
- 魔姝：首次登场；C 级气运之女、大乘六重修士，主动邀请徐霄进入其行动队伍。
- 四域顶级宗门：因压制法器竞拍一度集体敌视徐霄，后因萧家黑市供货而降低部分直接冲突动机。
