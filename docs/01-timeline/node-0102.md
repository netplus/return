# NODE-0102：轩辕拍卖会、道伤资源争夺与订婚变局

- **章节范围：** 第 773—792 章
- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

徐霄在轩辕仙城两日拍卖会中连续购入大道槐树根、化体神丹、混元破空盘、轩辕五行环和乾元护天阵盘，并利用系统赠送返还机制，将普通或道器级资源升级为通神仙玉、五行九天神威金轮等更高层级资源。拍卖过程中，他先向轩辕婉君赠送灵精和仙灵聚气玉，又将轩辕五行环赠给魔无花，分别建立轩辕家资源关系和魔无花复仇魔罗圣门的长期合作。

轩辕婉君原计划以九幽血菩提修复噬神大道道伤并与血无涯订婚。徐霄改以十颗太乙聚仙丹、五十颗金仙道丹及八颗含完美弑神大道的高阶丹药提供替代方案，促使轩辕婉君终止与血无涯的婚约。血宗围攻徐霄时，凤溪以太乙仙六重修为介入；徐霄使用五行九天神威金轮重创血无涯，噬魂血宗撤退并与万妖仙宗公开决裂。轩辕家随后同意改与徐霄联姻，两人完成订婚。返宗后，徐霄兑现凤溪资源，并以太乙聚仙丹促使龙九天及太上长老体系转为处理和承担这场对外冲突。

## 关键因果链

1. 徐霄高价竞拍并持续赠礼 → 系统返还大量灵精、太乙聚仙丹和高阶道器。
2. 轩辕婉君获得通神仙玉及完美弑神大道丹药 → 九幽血菩提不再是其修复道伤的唯一方案。
3. 魔无花获得轩辕五行环和长期丹药支持 → 对魔无天的复仇路线获得可执行资源。
4. 血无涯阻止订婚对象变更 → 徐霄与噬魂血宗进入正面对峙。
5. 凤溪接受资源并公开介入 → 血宗失去现场优势。
6. 五行九天神威金轮重创血无涯 → 噬魂血宗撤离并与万妖仙宗公开决裂。
7. 轩辕家接受新的道伤解决方案和政治现实 → 轩辕婉君与徐霄完成订婚。
8. 徐霄向凤溪、龙九天兑现资源 → 万妖仙宗高层转为内部消化冲突，而非撤销徐霄圣子身份。
9. 第 793 章转入姬雪恢复前世记忆与外出取回衣钵 → 开始新的个人成长阶段。

## 主要人物与状态变化

- **徐霄：** 鸿蒙真气增至七十四股；获得混元破空盘、乾元护天阵盘、五行九天神威金轮和天道神威御火剑；与轩辕婉君完成订婚。
- **轩辕婉君：** 获得多组修炼及大道资源；终止与血无涯的订婚安排，成为徐霄预定道侣。
- **血无涯：** 被规则道器绞碎肉身后依靠血灵仙体重聚并重伤；失去订婚关系，与徐霄及万妖仙宗进入公开敌对。
- **凤溪：** 精确修为确认为太乙仙六重；公开支持徐霄和轩辕联姻，获得十五颗太乙聚仙丹与大道天火剑。
- **魔无花：** 获得轩辕五行环和长期丹药支持，明确以击杀魔无天、重返魔罗圣门为目标。
- **龙九天：** 由主张撤销圣子身份转为协调太上长老保护徐霄。
- **赤裳：** 获得赤澜儿婚事的补充聘礼资源。
- **周紫薇：** 在轩辕仙城继续与徐霄维持关系，被万萱带回并面临禁闭。
