# NODE-0069：李香香结缘、矿区规则与首次人仙冲突

- **章节范围：** 第 521—528 章
- **粒度：** Story arc
- **核验状态：** `partial`

## 剧情摘要

徐霄完成飞升者登记后进入阴阳仙门六号矿坑一四六号矿队。范有通向他说明灵精兑换、矿工报酬和矿区管理方式，并出售仙界概要；徐霄由此确认天元界极品灵石可作为下品灵精使用，决定暂时隐藏真正资源规模，先研究灵藏仙域和阴阳仙门规则。

矿队长邹蒙带徐霄完成首次下矿。矿坑覆盖监测大阵，灵矿不能直接收入储物袋，矿工必须背筐交割。徐霄以灵精委托邹蒙代挖，把时间投入规则研究与关系建立，并逐步接触来自乾元小界的飞升女修李香香。

徐霄向李香香赠送十枚雷灵丹，系统返还仙灵冰魄剑；两人随后确立公开道侣关系。代挖、赠礼和矿区公开关系迅速引发舆论，并推动执事层介入。老许因范有通的提醒而采取弹性处理，但返回矿区的韩烟和司空浩南主张以宗门纪律处罚徐霄。第 528 章形成首次人仙执事级直接冲突，第 529 章转入正式处罚和化仙丹反制。

## 关键因果链

1. 徐霄完成登记并购买仙界概要 → 确认灵精兑换关系和矿役经济规则。
2. 加入一四六号矿队 → 掌握矿坑大阵、背筐交割和矿额制度。
3. 以灵精委托邹蒙代挖 → 腾出时间研究仙界并保持低调资源优势。
4. 与李香香持续接触并赠送雷灵丹 → 系统返还仙灵冰魄剑，双方关系升级。
5. 两人公开结为道侣 → 矿工和巡逻弟子舆论升级，执事层开始介入。
6. 韩烟、司空浩南返回矿区 → 冲突由矿工舆论上升到人仙执事级纪律处罚。

## 主要人物与状态变化

- **徐霄：** 建立首条仙界道侣关系；确认下界极品灵石可作为下品灵精使用；形成“资源代挖、规则研究、择机入宗”的矿区策略。
- **李香香：** 乾元小界飞升者、矿区气运对象；接受十枚雷灵丹并与徐霄确立公开道侣关系。
- **邹蒙：** 渡劫九重外门弟子和矿队长；承担矿区引导及代挖安排。
- **范有通：** 矿区外门长老；负责飞升者登记和基础信息交易，并要求执事适度照顾徐霄。
- **老许：** 人仙境矿区执事；确认代挖缺乏明确禁令，采取弹性处置。
- **韩烟：** 人仙三重矿区执事；因矿区纪律和自身经历主张严厉处罚徐霄。
- **司空浩南：** 矿区执事；因李香香与徐霄结为道侣形成持续敌意。
