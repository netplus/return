## 剧情摘要

徐霄在阴阳仙门正式审理中再次向尘玉、万青和罗方提供五行仙丹。尘玉在资源与邬秋控诉的共同推动下明确宣布：若玄光确有残害女修之事，阴阳仙门将保下邬秋。邬秋由临时带回调查对象转为获得太上长老保护并在阴阳仙门安置的天仙长老。

纯阳仙门方面，道阳以吕玄一等十具尸身进行占卜追凶，却遭天道规则反噬；万倍返还系统同时检测并屏蔽针对徐霄的卦象之力，使纯阳仙门无法锁定凶手。

徐霄随后向邬秋赠送九天荡魔剑，返还至尊仙器荡魔真武剑，并另行给予天仙巅峰魂丹。邬秋与徐霄关系进一步确立，但在陆续得知凌白烟、南宫嫣、罗素等既有关系后产生强烈冲突。第 666 章完成邬秋控诉、宗门安置和关系认知转折；第 667 章转入诸葛青天恢复后的新事件。

## 关键因果链

1. 徐霄向三位太上长老提供五行仙丹 → 尘玉、万青、罗方正式支持复核邬秋冤情。
2. 邬秋控诉玄光长期侵害女修 → 阴阳仙门获得保人和安置邬秋的正当理由。
3. 纯阳仙门以尸身占卜追凶 → 道阳遭天道反噬，系统屏蔽徐霄相关卦象。
4. 九天荡魔剑与魂丹赠送 → 邬秋获得长期战斗和修炼资源，关系继续深化。
5. 邬秋认识徐霄既有关系网络 → 从单一有缘人预期转为竞争性、矛盾化关系状态。
