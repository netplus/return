# NODE-0066：天元仙塔百层、极致肉身与跨宗结缘

- **章节范围：** 第 500—508 章
- **粒度：** Story arc
- **核验状态：** `partial`

## 剧情摘要

天元仙塔大乘试炼中，徐霄以大乘三重修为连续展示三昧真火、破灭神光、三光神水、万界归元、枯荣天毒以及风雷、五行等大道能力，从七十层一路突破至一百层。面对九十层后达到渡劫层级的守关妖兽，他先以多系术法完成克制与击杀；九十六层后又集中展示九天玉骨、佛肉金身、仙牛神虎之力和三十二道鸿蒙真气加持下的极致肉身。

一百层守关金龙拥有渡劫六重级别的肉身。徐霄先进行纯肉身对抗，在确认双方肉身强度相近后，结合术法击败金龙并打通天元仙塔，刷新历史纪录。其公开战力由“资源雄厚的大乘修士”上升为足以影响天元大陆宗门格局的渡劫后期级战略力量。

战力展示随即转化为跨宗关系重组。天元、青云、缥缈等仙宗高层主动推动云心月、陆雪瑶、紫霄和血葵与徐霄建立道侣或长期资源关系。徐霄向四人分别赠送十枚蕴仙丹和一柄先天灵宝神剑，系统合并返还四柄仙器神剑、一枚鸿蒙一气丹、一枚三千大道丹和一百六十三枚雷灵丹。其后，他又向六名撮合者赠送十二枚雷灵丹作为答谢。

## 关键因果链

1. 徐霄进入天元仙塔 → 多系大道和上古神通首次大规模公开展示。
2. 九十层后守关者进入渡劫层级 → 徐霄证明自身术法与持续灵力足以压制渡劫妖兽。
3. 九十六至一百层转入肉身主导 → 佛肉金身、九天玉骨、仙牛神虎之力与三十二道鸿蒙真气形成稳定肉身体系。
4. 打通一百层 → 无妄仙宗战略地位上升，各宗高层停止或压低敌对态度并争相建立关系。
5. 四名气运对象接受高阶资源 → 新一轮跨宗道侣和赠送返还网络形成。
6. 第 509 章开始幽冥天绝阵与新返还链 → 转入新的阵法冲突阶段。

## 主要人物与状态变化

- **徐霄：** 境界明确为大乘三重；鸿蒙真气增至三十二道；形成可对抗渡劫六重肉身、综合战力接近渡劫后期的公开战绩。
- **云心月：** 由天元仙宗神女和已验证赠送对象，进一步进入公开道侣安排及高阶资源网络。
- **陆雪瑶：** 青云仙宗掌门；在宗门高层推动下接受道侣安排与高阶赠礼，但个人态度仍有保留。
- **紫霄：** 缥缈仙宗公孙长谋弟子，S 级气运之女，接受首次高阶资源并进入道侣安排。
- **血葵：** 血刀门下高阶女修，接受高阶资源并进入道侣安排；完整身份和面板待确认。
