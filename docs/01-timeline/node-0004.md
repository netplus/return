# NODE-0004：虎啸城赠礼与林嫣儿结缘

- 节点类型：剧情阶段（story arc）
- 状态：`verified`

## 剧情摘要

徐霄为建立可持续的系统返还循环，带陆大年前往虎啸城采购筑基丹与低阶法器。在紫来商行，他识别出气运之女紫韵，并以合理的人情往来赠出下品法钗，首次赠送触发千倍暴击，返还绝品法器九天神凤钗。

返程途中，徐霄介入外门弟子林嫣儿遭商家欺骗的纠纷，确认其为 C 级气运之女并赠送十枚筑基丹。林嫣儿首次接受赠礼触发百倍暴击，返还绝品驻颜丹。回宗后，徐霄境界由筑基一重快速恢复至筑基四重。林嫣儿登门致谢并为其按摩，徐霄再以答谢为由赠送三件下品法器，获得三件中品法器的普通十倍返还。至第 10 章，林嫣儿与徐霄形成稳定、可继续发展的赠送关系，外门对徐霄的善名与关注显著扩散；第 11 章转入新的气运之女，故在此结束节点。

## 关键因果链

1. 一百上品灵石提供启动资金。
2. 徐霄采购批量筑基丹与低阶法器，建立可重复赠送的资源池。
3. 对紫韵的首次有效赠送触发千倍暴击，获得九天神凤钗。
4. 徐霄帮助林嫣儿解决商家纠纷，使后续赠送具有自然、合理的因果基础。
5. 对林嫣儿首次赠送筑基丹触发百倍暴击，获得绝品驻颜丹。
6. 林嫣儿主动登门致谢，双方关系由一次性帮助转为可持续互动。
7. 第二次对林嫣儿赠送三件下品法器，仅触发普通十倍返还，进一步确认首次赠送暴击与后续普通返还的差异。

## 主要状态变化

- 徐霄：境界由筑基一重恢复至筑基四重；形成批量采购、合理赠送、返还再利用的稳定策略。
- 紫韵：首次登场；紫来商行掌柜；识别为气运之女；完成首次有效赠送。
- 林嫣儿：首次登场；缥缈宗外门弟子；练气九重；C 级气运之女；与徐霄建立持续关系并获得筑基资源与三件下品法器。
- 陆大年：陪同徐霄采购并见证赠送事件，继续承担协助角色。

## 系统与物品增量

- 首次赠送紫韵：下品法钗 → 千倍暴击 → 九天神凤钗。
- 首次赠送林嫣儿：十枚筑基丹 → 百倍暴击 → 绝品驻颜丹。
- 后续赠送林嫣儿：三件下品法器 → 普通十倍返还 → 三件中品法器。
- 新确认规则：每名气运之女的首次有效赠送会稳定触发暴击；同一对象后续赠送可回归基础倍率。

## 场景与世界信息

- 虎啸城位于盘龙大陆东部、东莱国境内，是邻近缥缈宗的重要修真物资交易城市。
- 紫来商行为虎啸城大型商行。
- 缥缈宗地位超然于东莱国，不受其直接约束。
