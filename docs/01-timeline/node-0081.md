- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

时间推进五年。陆道离携旧日凤钗前往探望厉红魅，却撞见厉红魅已与徐霄确立稳定关系，旧情修复彻底失败。五年间徐霄升至人仙三重，组建十余人的内门执法队伍，并以九霄山河图一击收纳血灵宗三名人仙长老，完成血灵宗清剿任务。凌白烟、莫问书、梦琳、云姑心和邹蒙均进入其长期执法与护院体系。

随后阴阳、纯阳、五灵三大仙门的人仙交流大会开幕。五灵仙门掌门云花海首次登场，并被系统识别为 SSS 级气运之女。大会采用三宗轮流车轮战规则，凝气人仙与纯阳金身等高阶人仙体系公开。南宫嫣到场后被安排迎战二气人仙金刚丰；徐霄判断实力差距过大，决定代其出战。第 623 章由此转入徐霄亲自参赛的擂台主战阶段。

## 关键因果链

1. 陆道离试图挽回厉红魅 → 亲眼确认其与徐霄关系稳定 → 旧情冲突转为长期敌意。
2. 五年自动修炼与资源积累 → 徐霄升至人仙三重并建立执法班底。
3. 血灵宗炼化凡人气血 → 徐霄执行清剿任务 → 九霄山河图首次确认可瞬间收纳人仙巅峰合体目标。
4. 三宗交流大会开幕 → 凝气人仙体系及车轮战规则公开。
5. 云花海与罗素重逢 → 系统确认云花海为 SSS 级气运之女。
6. 南宫嫣被安排对阵二气人仙金刚丰 → 徐霄决定代战 → 下一节点进入擂台主战。

## 主要人物与状态变化

- **徐霄：** 年龄 1039 岁，境界人仙三重；拥有十余名执法弟子和护院班底；以九霄山河图完成血灵宗清剿；决定代南宫嫣参赛。
- **陆道离：** 挽回厉红魅失败，对徐霄的私人冲突进一步固化。
- **厉红魅：** 明确拒绝陆道离，维持与徐霄的长期关系。
- **凌白烟、莫问书、梦琳、云姑心、邹蒙：** 进入徐霄的执法或护院体系；凌白烟、莫问书已至人仙四重，邹蒙升至人仙一重。
- **罗素：** 升至地仙八重；在三宗高层面前公开徐霄的长期资源支持。
- **云花海：** 五灵仙门掌门、天仙上境、罗素旧友；被系统识别为 SSS 级气运之女。
- **南宫嫣：** 作为外门强者参加交流大会，因对手实力过强由徐霄主动代战。
