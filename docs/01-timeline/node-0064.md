## 剧情摘要
龙矶渡过第七次雷劫五年后，无妄仙宗的高阶战力继续增长。第一婵在徐霄长期提供的丹药与灵宝支持下晋升大乘；凤仪、玄阴女尊、百里海棠和萧烬璃等人也已先后进入大乘层级。天元仙宗渡劫七重太上长老素青携神子楚霄、神女云心月到访，邀请无妄仙宗参加天山论剑。楚霄因徐霄的名声、实力及其接近云心月而形成持续敌意。

徐霄首次向云心月赠送十枚雷灵丹，系统以万倍暴击返还佛陀金身丹，并普通返还九枚化仙丹。随后姬雪的元灵仙体觉醒，恢复部分前世记忆，被确认是雪瑶仙帝转世；其须臾空间和自带仙界法器重新激活，境界由合体九重跃升至大乘上境。徐霄向姬雪赠送先天冰系神剑和十枚蕴仙丹，但完整返还链未稳定显示。

无妄仙宗队伍抵达天元仙宗后，徐霄继续扩展长期关系网络：苏瑶接受灵宝并与徐霄羁绊度提升至 2。灵霄仙宗、黑魔圣宗及蓬莱仙宗随后抵达。徐霄以仙神魂胎神识发现，蓬莱仙宗三名渡劫太上长老海岚、葬花、北风，以及同行二十余名大乘、合体修士均已被冰寒阴灵夺舍；其形态与阴煞界阴魂不同。徐霄暂不公开处理，决定等待对方暴露目的。第 494 章转入月幽冥赠送与新的关系推进，本节点在第 493 章收束。

3. 云心月首次赠送触发万倍暴击，返还佛陀金身丹与九枚化仙丹。
4. 姬雪觉醒元灵仙体和雪瑶仙帝前世记忆，进入大乘上境并恢复仙界资源体系。
