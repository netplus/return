## 剧情摘要

十年后，徐霄已升至人仙九重，并继续向柳清浅提供高阶资源。他将九天神玉带赠予柳清浅，系统返还至尊仙器缚仙绳。随后天一仙门爆发重大变故：邬秋囚禁并折磨玄光长老十年，事发后携至尊仙器地脉岩火剑逃往玉京仙域。天一仙门以地脉岩火剑为追捕彩头，邀请灵藏仙域其余六宗共同缉拿。

阴阳仙门由东方青、莫介、炎阳等高层带队，徐霄驾驶九霄玉舟前往玉京仙域。七宗抵达众愿佛门后公开叫阵，诸葛青天借现场震惊取得系统收益。众愿佛门方丈惠慈承认邬秋位于众佛小世界的阿鼻地狱，但拒绝直接交人，只同意开放八层无间地狱供七宗自行追捕。

对峙期间，刹女仙门掌门洛银纱主动接近徐霄并吸收其气运，两人建立明确亲密关系。第 650 章，七宗完成队伍编组并进入众佛小世界第一层铁钩狱，追捕行动由跨域交涉正式转入无间地狱内部推进。

## 关键因果链

1. 邬秋杀害玄光并携地脉岩火剑逃亡 → 天一仙门发起七宗联合追捕。
2. 地脉岩火剑被设为竞争奖励 → 阴阳仙门高层大规模参与跨域行动。
3. 众愿佛门拒绝直接交人但开放众佛小世界 → 冲突由宗门外交转为八层无间地狱追捕。
4. 洛银纱主动吸收徐霄气运 → 徐霄与刹女仙门掌门建立持续关系线。
5. 第 650 章进入铁钩狱 → 第 651 章开始具体狱层推进和战斗。
