## 剧情摘要

徐霄代南宫嫣登上三宗人仙交流大会擂台，以炼体实力一脚击飞二气人仙金刚丰，随后结合九天神玉带、完美冰系大道、完美剑之大道、万龙鎏金甲和两柄至尊仙剑连续击败纯阳、五灵两宗选手。面对五气人仙焰灵，他先以冰系大道压制火灵道体，再以十颗仙元丹补偿伤势，系统返还五气朝元丹及四十五颗五行仙丹。

两宗决定让剩余选手全部围攻，徐霄仍以至尊防御和莲花剑气在极短时间内击溃百余名顶级人仙。纯阳、五灵两宗最终弃权，阴阳仙门宣布徐霄获得“天南第一人仙”称号。第 633 章转入太上长老责令徐霄与罗素分手的新冲突。

## 关键因果链

1. 南宫嫣面对二气人仙风险较高 → 徐霄代其出战。
2. 金刚丰被一脚击飞 → 徐霄炼体实力首次在三宗高层面前公开。
3. 焰灵以火灵道体出战 → 徐霄公开完美冰系大道并完成补偿赠送。
4. 十颗仙元丹赠送焰灵 → 返还五气朝元丹与四十五颗五行仙丹。
5. 徐霄挑战两宗全部剩余选手 → 万龙鎏金甲与莲花剑气形成压倒性群战结果。
6. 两宗弃权 → 徐霄获得天南第一人仙称号。

- **徐霄：** 法、体、剑三修实力公开；取得天南第一人仙称号；完美冰系大道、完美剑之大道和至尊仙器组合形成稳定地仙级战力表现。
