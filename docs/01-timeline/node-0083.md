# NODE-0083：责令分手、太上长老转向与金华气运之敌

- **章节范围：** 第 633—638 章
- **粒度：** Story arc
- **核验状态：** `partial`

## 剧情摘要

三宗交流大会结束后，阴阳仙门太上长老尘玉因徐霄公开与多名女修亲密往来，联合万青、罗方责令其立即分手。尘玉被系统识别为 SSS 级气运之女。徐霄没有接受分手要求，而是向三位太上长老各赠十颗高品质五行仙丹；万青、罗方继续认可其与罗素的关系，尘玉也由强硬问责转为接受徐霄对现有关系和相关伤势长期负责。

太上长老离场后，徐霄向大会中受伤的焰灵赠送一件仙剑，并承诺对可能出现的后遗症负责，系统返还至尊仙器破天斩金剑。纯阳仙门内门长老金华由徐霄展露的实力推断青锋等人可能死于徐霄之手，随后被系统识别为气运之敌。吕玄一和金华当场问责，但东方青以无直接证据为由公开保护徐霄并驱逐纯阳仙门一行。

第 638 章完成三宗大会后续冲突和纯阳仙门撤离；第 639 章转入诸葛青天出关、云姑心汇报和新的宗门内部冲突。

## 关键因果链

1. 徐霄在大会公开多重关系 → 尘玉等太上长老责令分手。
2. 徐霄向三位太上长老赠送高品质五行仙丹 → 问责立场转为接受并维持现有关系安排。
3. 焰灵受伤及徐霄承诺负责 → 仙剑赠送成功并返还破天斩金剑。
4. 徐霄展示足以击杀地仙的实力 → 金华将青锋死亡与徐霄联系起来。
5. 金华被识别为气运之敌、纯阳仙门公开问责 → 东方青以掌门身份明确保护徐霄。
6. 纯阳仙门撤离 → 三宗交流大会及其直接余波结束。

## 主要人物与状态变化

- **徐霄：** 以三十颗五行仙丹化解太上长老分手问责；向焰灵赠送仙剑并获得破天斩金剑；与纯阳仙门的青锋案矛盾公开化。
- **尘玉：** 阴阳仙门太上长老、SSS 级气运之女；由强制分手转为接受徐霄对多重关系长期负责。
- **万青、罗方：** 收下五行仙丹，继续认可徐霄与罗素关系，并接受其现有关系结构。
- **焰灵：** 接受仙剑和长期伤势补偿承诺，与徐霄的资源关系进一步建立。
- **金华：** 纯阳仙门内门长老、青锋师尊；识别徐霄为青锋案嫌疑人，并被系统确认为气运之敌。
- **东方青：** 在跨宗门问责中公开保护徐霄，将其宗门战略价值置于纯阳仙门压力之上。
- **吕玄一：** 青锋死亡调查由怀疑升级为公开宗门冲突，但因无直接证据和阴阳仙门保护而撤离。
