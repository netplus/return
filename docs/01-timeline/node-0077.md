- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

灵矿谈判破裂后，徐霄以完美剑之大道同时驱动九阴绝寒剑与至尊神火剑，瞬间击杀两名纯阳仙门人仙九重弟子及金蟾族高层。随后山河灵图收走矿区修士，南宫嫣、厉红魅和十六城高层清除金蟾族驻地，海底灵矿正式纳入阴阳仙门势力范围。

飞鱼城庆功期间，徐霄向厉红魅赠送十颗化仙丹，首次赠送触发千倍返还鸿蒙一气丹，其余九颗返还九颗仙元丹。厉红魅基于长期断绝的地仙仙路与徐霄确立关系；徐霄继续赠送厚土御天剑和人仙巅峰大道神丹，分别返还至尊仙器九岳覆天剑与三千天道丹。羁绊升至二级后，徐霄服用返还丹药，完美领悟力之大道。

金蟾族幸存人仙金幻带纯阳仙门弟子返回调查。徐霄以力之大道近身击杀雨剑龙，收走其余人员，并利用曹达伪造海底地火消息引来青锋。青锋为地仙一重，最终被地仙顶级极道灵火符直接灭杀；系统确认任务完成并发放一座额外传送仙台。金蟾族分支、青锋及其调查链被彻底清除，灵矿控制和系统任务同时闭环。

## 关键因果链

1. 完美剑之大道与双至尊仙剑结合 → 徐霄在人仙层级形成压倒性战力并清除金蟾族高层。
2. 金蟾族分支灭亡 → 海底灵矿转由阴阳仙门势力持续开采。
3. 厉红魅接受丹药和仙器 → 断裂的地仙仙路重启并与徐霄确立长期关系。
4. 三千天道丹再次返还并服用 → 徐霄完美领悟力之大道，可短暂撕裂仙界空间。
5. 金幻和纯阳仙门调查人员返回 → 徐霄利用灭口与假情报反向引出青锋。
6. 青锋被极道灵火符击杀 → 气运之敌任务完成，额外传送仙台到账。

## 主要人物与状态变化

- **徐霄：** 完美掌握剑之大道和力之大道；以至尊仙器、山河灵图和地仙顶级符箓完成灭族、占矿及青锋任务。
- **厉红魅：** 接受化仙丹、厚土御天剑和大道神丹；与徐霄确立关系，羁绊度升至二，并重新获得晋升地仙的长期资源路径。
- **南宫嫣：** 参与金蟾族驻地清除；对徐霄战力产生明显认可，但因其与厉红魅关系确立而出现持续关系冲突。
- **金大友：** 与金蟾族高层一同被徐霄双剑击杀，金蟾族分支随后灭亡。
- **金幻：** 金蟾族幸存人仙，返回调查时被徐霄伏击并炼化。
- **青锋：** 地仙一重；被引至金蟾族驻地后遭极道灵火符击杀，系统气运之敌任务完成。
