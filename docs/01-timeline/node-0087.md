# NODE-0087：徐霄保人、三方站队与疯狂返还

- **章节范围：** 第 659—662 章
- **粒度：** Story arc
- **核验状态：** `partial`

## 剧情摘要

徐霄在离开无间地狱后公开阻止天一仙门处决邬秋。为将邬秋带回阴阳仙门调查，他向随行天仙、地仙巅峰长老承诺高品质五行仙丹或仙元丹。东方青、莫介、炎阳、青鸾等阴阳仙门高层因此集体改变态度，公开主张玄光存在邪修嫌疑，并要求先行调查邬秋冤情。

洛银纱与琉璃代表刹女仙门加入保人阵线，惠慈及众愿佛门随后以维护佛门清净为由对天一仙门施压。天一仙门在多宗联合威慑下暂时放弃带走邬秋，其他宗门陆续撤离，外部冲突告一段落。

返程途中，徐霄履行资源承诺并完成多笔系统返还：向瑶光赠送十颗仙元丹，返还鸿蒙一气丹与四十五颗五行仙丹；向丁静、阴萱赠丹分别返还十颗和三十颗五行仙丹；向青鸾赠送十颗五行仙丹，返还一百颗玄元仙丹；向东方青赠送十颗五行仙丹后原样返还；向邬秋赠送十颗五行仙丹，首次赠送触发鸿蒙一气丹，并返还九十颗玄元仙丹。队伍最终回到阴阳仙门，第 663 章转入太上长老对邬秋的宗门内审理。

## 关键因果链

1. 徐霄公开保下邬秋 → 与天一仙门的处置立场直接冲突。
2. 向阴阳仙门长老承诺资源 → 宗门高层集体转为支持将邬秋带回调查。
3. 刹女仙门与众愿佛门加入 → 天一仙门失去武力和舆论优势并暂时退让。
4. 邬秋避免即时处决 → 对徐霄的信任和情感显著提升。
5. 返程履行赠丹承诺 → 徐霄稳定多位宗门高层，同时通过系统补充鸿蒙一气丹、五行仙丹和玄元仙丹。
6. 返回阴阳仙门 → 冲突由外部抢人转入太上长老层面的正式审理。

## 主要人物与状态变化

- **徐霄：** 以资源组织跨宗门保人联盟；进一步巩固其在阴阳仙门高层中的实际影响力；完成多笔高阶丹药返还。
- **邬秋：** 由待处决对象转为阴阳仙门带回调查对象；对徐霄的信任与情感明显提升；接受十颗五行仙丹。
- **东方青：** 从要求交还邬秋转为代表阴阳仙门公开保人，并接受资源承诺。
- **洛银纱、琉璃：** 代表刹女仙门站队徐霄，巩固刹女仙门与徐霄的合作关系。
- **惠慈：** 率众愿佛门加入威慑，实际帮助邬秋脱离天一仙门控制。
- **独孤惊云、崔云：** 在多宗联合压力下暂时放弃邬秋，敌意进一步加深。
- **诸葛青天：** 未参与资源承诺与保人行动，返程分配中被排除，再次因徐霄受挫。
