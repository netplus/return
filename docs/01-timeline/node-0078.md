# NODE-0078：南宫嫣关系修复、返宗调查与东方青转向

- **章节范围：** 第 598—603 章
- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

青锋任务完成后，徐霄以海底地火作为对外解释，准备返回阴阳仙门。南宫嫣因厉红魅关系拒绝同行，徐霄将常用顶级空间仙器山河灵图及一颗人仙巅峰魂丹赠予她，分别返还至尊仙器九霄山河图与地仙巅峰魂丹。南宫嫣接受资源并与徐霄正式确立关系；返宗后羁绊升至二级。

返程和回宗期间，莫问书与凌白烟获得看守资源，其中凌白烟三颗化仙丹触发三颗仙元丹返还。纯阳仙门掌门吕玄一认定青锋死亡可能与阴阳仙门有关，派金华、玄怀调查南海；但调查只能确认高阶火灾痕迹，无法获得阴阳仙门直接证据，事件暂时平息。

徐霄继续向罗素赠送十颗仙元丹，返还十颗五行仙丹。东方青得知徐霄与南宫嫣的关系后公开问责，徐霄先后赠送三颗和两颗五行仙丹。系统确认赠送气运之子的物品会原封不动返还。东方青获得资源后彻底改变立场，公开支持徐霄与罗素、南宫嫣的关系，并同意让厉红魅以外门长老身份进入阴阳仙门。

## 关键因果链

1. 南宫嫣因厉红魅关系拒绝返程 → 徐霄以山河灵图与魂丹修复双方关系。
2. 两项赠送完成 → 九霄山河图和地仙巅峰魂丹返还，南宫嫣羁绊升至二。
3. 青锋死亡引发纯阳仙门调查 → 因缺乏证据且地火痕迹真实，调查阶段性平息。
4. 东方青公开问责徐霄 → 徐霄赠送五颗五行仙丹。
5. 气运之子返还规则确认 → 五颗丹药全部原样返还，赠送不产生净资源损失。
6. 东方青获得高品质资源 → 从反对者转为支持者，并批准厉红魅入宗安排。

## 主要人物与状态变化

- **徐霄：** 完成南宫嫣关系修复；返回阴阳仙门后以资源改变东方青立场，并为厉红魅取得外门长老入口。
- **南宫嫣：** 接受山河灵图和人仙巅峰魂丹；与徐霄正式确立关系，羁绊度提升至二。
- **东方青：** 接受五颗五行仙丹；确认气运之子原样返还规则后，从公开问责转为全面支持徐霄。
- **罗素：** 接受十颗仙元丹，继续维持长期资源支持关系。
- **凌白烟：** 接受三颗化仙丹，并明确形成“反对行为但接受资源”的稳定行动模式。
- **莫问书：** 接受三颗化仙丹，继续承担看守和协助角色。
- **厉红魅：** 获东方青批准以外门长老身份加入阴阳仙门。
- **吕玄一：** 纯阳仙门掌门，因青锋死亡将徐霄和东方青视为潜在敌对目标。
