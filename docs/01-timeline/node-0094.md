# NODE-0094：人族养伤小队、青木城阵眼与首战收束

- **章节范围：** 第 706—715 章
- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

玄灵、玄雪接受徐霄赠送的玄元仙丹后，玄鸟族继续追踪青木城方向的人族养伤小队。徐霄在包围中识别出天玄仙宗执事周紫薇为 SS 级气运之女，阻止其自爆，放走整支人族小队，并以“人族高层卧底”身份取得其信任。系统返还三千大道丹与金仙道丹；徐霄随后服用太初仙体丹和三千大道丹，体质进化为太初仙体、修为升至天仙四重，并完美领悟感知大道。

天水城将玄鸟族补入八大妖族，并组织玄仙精锐支援青木城。徐霄随赤澜儿、玄灵、金虚等抵达前线，确认凤天晴、孔青负责青木城防务，并在保护白鹤族阵眼小队时识别鹤仙儿和青曼。人族玄仙来袭后，徐霄击杀一名追杀青曼的玄仙，治愈青曼并与其确立关系；随后正面击退天地玄仙赵四尊，迫使天玄仙宗小队撤退，保住阵眼。向赤澜儿赠送缚仙绳后，系统返还道器镇魂黑链。

## 关键因果链

1. 玄鸟族追上重伤天玄小队 → 周紫薇准备自爆 → 徐霄识别其气运资质并放人结善缘。
2. 玄元仙丹赠送周紫薇 → 返还三千大道丹与金仙道丹 → 徐霄后续能力继续扩展。
3. 太初仙体丹与三千大道丹服用 → 太初仙体、天仙四重与完美感知大道形成。
4. 天水城组织青木城支援 → 徐霄进入大仙域人妖正面战场。
5. 阵眼遭人族玄仙袭击 → 徐霄救下青曼并击退赵四尊 → 阵眼保住、人族败退。
6. 缚仙绳赠送赤澜儿 → 返还道器镇魂黑链。

## 主要人物与状态变化

- **徐霄：** 晋升天仙四重；道元圣体进化为太初仙体；完美领悟感知大道；首次在青木城前线公开展示可压制天地玄仙的战力。
- **周紫薇：** 天玄仙宗玄仙执事、SS 级气运之女；将徐霄误认为人族高层卧底并带队脱险。
- **玄雪：** 接受美人计安排，与徐霄正式公开对象关系，并获得长期天凤血丹承诺。
- **青曼：** 青花蛇族族长、A 级气运之女；被徐霄救治并确立关系。
- **鹤仙儿：** 白鹤族 SS 级气运之女，参与青木城阵眼布置。
- **凤天晴、孔青：** 万妖仙宗青木城前线负责人。
- **赵四尊：** 天玄仙宗天地玄仙，被徐霄正面击退。
