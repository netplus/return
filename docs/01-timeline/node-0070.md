# NODE-0070：化仙丹反制、神魂暗杀与韩烟结缘

- **章节范围：** 第 529—536 章
- **粒度：** Story arc
- **核验状态：** `partial`

## 剧情摘要

韩烟以矿区执事身份宣布处罚徐霄、李香香和邹蒙。徐霄没有直接对抗人仙威压，而是利用资源优势向韩烟赠送三枚化仙丹。韩烟接受赠礼后确认徐霄和李香香没有违反明确矿区规则，撤销十年与一年禁闭处罚，只保留对邹蒙的短期连坐处罚。系统确认韩烟为 B 级气运之女，首枚化仙丹触发千倍暴击，返还鸿蒙一气丹，其余两枚返还两枚仙元丹。

化仙丹被炼化后，韩烟由人仙三重晋升人仙四重，并开始重新评估徐霄的资源规模与关系价值。与此同时，司空浩南因处罚失败和李香香关系受挫，安排三名精通神魂秘术的手下暗杀徐霄。三人未能伤及徐霄，随后失联或死亡；司空浩南确认徐霄状态如常，但完整神魂反制过程仍未得到直接证据。

徐霄继续向韩烟赠送七枚化仙丹，两人的关系由执法者与被处罚矿工转为公开接触和道侣意向。韩烟计划借外门长老巡视机会，帮助徐霄进入阴阳仙门，并考虑让其拜入自己大师姐门下。第 535 章出现至尊仙器万龙鎏金甲返还，但七枚化仙丹与该仙器的逐笔倍率和精确触发关系尚未完整确认。相关消息在矿区和阴阳仙门扩散，引出外门长老团直接到场。

## 关键因果链

1. 韩烟正式处罚徐霄等人 → 矿区冲突从舆论升级为人仙执事行政处置。
2. 徐霄赠送三枚化仙丹 → 韩烟撤销主要处罚并重新解释矿区规则。
3. 首次有效赠送韩烟 → 系统返还鸿蒙一气丹和仙元丹，确认仙界人仙对象仍适用返还机制。
4. 韩烟炼化化仙丹晋升人仙四重 → 对徐霄资源和关系价值的判断发生长期变化。
5. 司空浩南发动神魂暗杀 → 三名暗杀者失败，徐霄的神魂防护底牌得到结果性验证。
6. 后续七枚化仙丹与关系推进 → 韩烟公开承认接触关系，并开始为徐霄进入阴阳仙门铺路。
7. 至尊仙器万龙鎏金甲返还与消息扩散 → 第 537 章外门长老团到场，进入新的宗门准入阶段。

## 主要人物与状态变化

- **徐霄：** 以资源而非正面对抗解除执事处罚；神魂暗杀后保持无损；开始将矿区生存策略升级为进入阴阳仙门的宗门路线。
- **韩烟：** B 级气运之女、基础倍率 10、羁绊度初始 1；炼化化仙丹后由人仙三重晋升人仙四重；由处罚执行者转为徐霄公开关系对象和宗门引荐者。
- **李香香：** 一年禁闭被撤销；继续维持与徐霄的公开关系，但对韩烟介入产生竞争与不安。
- **司空浩南：** 处罚失败后转入秘密神魂暗杀；三名手下失败后敌意和失控程度继续升级。
- **邹蒙：** 代挖行为被认定存在连坐责任，受到十天禁闭处罚。
- **西门恨天：** 阴阳仙门内针对徐霄的新对立者，因韩烟关系线产生直接敌意，并准备借矿区巡视压制徐霄。
