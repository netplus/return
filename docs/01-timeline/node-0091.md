# NODE-0091：妖族身份豁免、天水城灵田与仙丹种植

- **章节范围：** 第 681—688 章
- **粒度：** Story arc
- **核验状态：** `partial`

## 剧情摘要

青鸾显露上古青鸾妖身，凤青玄显露纯血天凤血脉。两人的妖族血统使阴阳仙门至尊天仙获得免除神魂烙印的优待，并共同为徐霄担保，使徐霄也免于万魂盘烙印。徐霄由被征服的人族修士转为妖族体系内的特殊关系对象。

进入大仙域天水城后，赤澜儿与徐霄确立亲密关系。灵藏七宗修士被要求以自身灵力催熟五行炫光草和阴阳玄元草，每年按人头上交十株，修炼资源和境界稳定受到长期威胁。金虚负责统计上交数量，徐霄则获任灵田巡察。

青鸾接受十颗仙元丹和十颗五行仙丹，系统分别返还一百颗五行仙丹和一百颗玄元仙丹。徐霄进一步建立“用仙丹补偿灵田灵力消耗”的资源策略，先覆盖洛银纱、琉璃，随后承诺支持姬雪、柳清浅和绝柔。第 688 章玄鸟族玄仙玄雪被系统识别为 S 级气运之女；第 689 章凤青玄从万妖仙宗返回，进入凤族血令与新身份阶段。

## 关键因果链

1. 青鸾与凤青玄显露高阶妖族血脉 → 阴阳仙门核心高层免除神魂烙印。
2. 二人为徐霄担保 → 徐霄免除烙印并获得妖族特殊身份。
3. 赤澜儿与徐霄建立关系 → 徐霄在天水城获得巡察权和资源操作空间。
4. 妖族强制灵藏修士高强度催熟灵植 → 七宗修士面临长期境界倒退风险。
5. 徐霄以仙丹补偿灵力损耗 → 将压榨性种植任务转化为新的赠送返还渠道。
6. 玄雪被识别为 S 级气运之女 → 妖族气运对象范围扩展至玄仙层级。

## 主要人物与状态变化

- **玄雪：** 玄鸟族玄仙族长，被识别为 S 级气运之女，负责灵田巡视。
