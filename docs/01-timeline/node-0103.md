# NODE-0103：雪瑶仙帝归来、太上长老收编与孔青覆灭

- **章节范围：** 第 793—807 章
- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

姬雪恢复雪瑶仙帝的完整记忆和真容，前往飘雪仙域取回二十六丝鸿蒙真气，以天地人三柄规则道器破除朱萧布置的至尊太乙噬灵大阵，并展开针对旧部叛徒和相关仙宗的复仇。与此同时，万妖仙宗四大太上长老龙贞、凤四老、孔金、鹤霜英介入徐霄引发的宗门危机。徐霄以太乙聚仙丹建立高层保护网络，推动万妖仙宗在噬魂血宗和仙帝宫法令冲突中继续维护其圣子身份。

孔青随后组织门人围堵天魁峰，徐霄将其击杀，完成气运之子任务。系统把丹药返还库上限提升至大罗仙，并通过高层赠礼返还三十颗大罗鸿蒙丹。第 807 章确认徐霄已为金仙一重、鸿蒙真气七十八股、寿命超过一千万年；飘雪仙域复仇阶段告一段落，第 808 章转入赴飘雪仙域直面雪瑶仙帝。

## 关键因果链

1. 姬雪恢复前世记忆并寻找衣钵 → 雪瑶仙帝身份与力量回归。
2. 朱萧试图夺取鸿蒙真气 → 雪瑶破阵并启动飘雪仙域复仇。
3. 徐霄向万妖仙宗高层提供太乙聚仙丹 → 四大太上长老形成政治保护网络。
4. 孔青发动天魁峰围堵 → 徐霄将其击杀并完成系统任务。
5. 气运之子任务完成 → 丹药返还库提升至大罗仙。
6. 第 807 章战局与系统结算收束 → 第 808 章进入雪瑶仙帝直接问责阶段。
