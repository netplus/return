# NODE-0089：地仙跃迁、三宗上门与仙帝传承威慑

- **章节范围：** 第 667—676 章
- **粒度：** Story arc
- **核验状态：** `partial`

## 剧情摘要

诸葛青天恢复伤势并觉醒前世力量后重返宗门舆论中心。徐霄服用万佛金身丹，鸿蒙真气增至五十五股，修为由人仙巅峰连续突破至地仙三重，并获任执法堂预备执法长老。随后他向丁静赠送至尊仙器九阴绝寒剑，返还道器大道玄冰剑；丁静接受赠礼并与徐霄确立关系，执法堂与全宗舆论再次爆炸。

天一仙门联合金光佛门、九阴玄门上门，要求废除徐霄修为、交出邬秋并收回地脉岩火剑。徐霄公开为邬秋辩护，拒绝三宗条件，并主动提出同时迎战独孤惊云、崔云、黑无忌等八名高手。战斗中，他以万佛金身、仙神魂胎、遁之大道、力之大道、破灭神光、九霄山河图及五柄至尊仙剑形成全面压制，毁去多名天仙法身并收纳其神魂。

徐霄以“上古仙帝传承”解释自身资源与战力，三宗在战败后退走，不再追究邬秋。阴阳仙门高层由担忧转为全面拥护，徐霄的宗门身份正式转为内门长老并获得堪比至尊天仙的战略地位。第 676 章完成宗门地位重构和内部舆论余波；第 677 章转入大仙域来人与灵藏仙域危机。

## 关键因果链

1. 万佛金身与境界连续突破 → 徐霄晋升地仙三重并获得执法堂预备长老身份。
2. 九阴绝寒剑赠送丁静 → 返还大道玄冰剑，丁静关系线公开化并引爆宗门舆论。
3. 三宗要求交人废功 → 徐霄公开将邬秋行为定义为替天行道并拒绝妥协。
4. 徐霄一敌八并碾压三宗高手 → “上古仙帝传承”成为外界解释其战力与资源的公开叙事。
5. 三宗败退 → 邬秋追责暂时终结，徐霄在阴阳仙门的地位上升至至尊天仙级战略核心。

## 主要人物与状态变化

- **徐霄：** 晋升地仙三重；鸿蒙真气增至五十五股；修成万佛金身；获任执法堂预备执法长老并随后转正内门长老；公开具备压制多名高阶天仙的战力。
- **丁静：** 接受九阴绝寒剑，与徐霄关系正式确立。
- **诸葛青天：** 恢复伤势并觉醒前世力量，但因丁静关系变化再次陷入强烈冲突。
- **邬秋：** 在三宗上门追责中被徐霄公开保下，阴阳仙门长老身份得到进一步确认。
- **独孤惊云、崔云、黑无忌等：** 联手挑战徐霄失败，部分法身被毁、神魂被收纳后归还。
- **尘玉、万青、罗方：** 由担忧徐霄挑起宗门大战转为认可其仙帝传承和战略价值。
