# NODE-0104：雪瑶仙帝问责、仙帝宫拘禁与徐霄脱困

- **章节范围：** 第 808—821 章
- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

徐霄向万妖仙宗高层坦言刘爱花极可能就是恢复前世身份的雪瑶仙帝，并以太乙聚仙丹委托龙贞等六名高层在出发前处置天穹。天翎接受祖凤血丹、太乙聚仙丹和大道天金剑，与徐霄建立秘密关系；天穹随后被击杀，系统将符箓与阵法返还库上限提升至大罗仙。

万妖仙宗代表随太初仙帝宫前往飘雪仙域。徐霄向周紫薇赠送金仙巅峰冰符，返还大罗九重混元大罗神冰符。雪瑶完成仙帝加冕后，将徐霄、熊大及其十余名关系人物留在飘雪仙帝宫，种下控制阵法并安排为侍女、仆人。上官清作为雪瑶核心亲信负责执行仙帝宫安排，并被系统识别为 SSS 级气运之女。

徐霄向雪瑶展示并赠送十颗大罗鸿蒙丹，系统返还一千颗大罗鸿蒙丹，但雪瑶仍坚持将其拘禁并斩断情欲。徐霄借雪瑶松动规则道器束缚的瞬间激活混元破空盘，成功逃离仙帝宫；双方暂时维持师徒与资源关系，留在仙帝宫的众人继续受雪瑶管束。

## 关键因果链

1. 徐霄确认刘爱花与雪瑶身份线索 → 万妖仙宗高层预判仙帝问责。
2. 太乙聚仙丹委托龙贞等六人 → 天穹被击杀，符箓阵法返还上限升级至大罗仙。
3. 天翎接受复合赠礼 → 大道天金剑返还为天道神威绝金剑，双方建立秘密关系。
4. 周紫薇接受金仙巅峰冰符 → 返还大罗九重混元大罗神冰符。
5. 雪瑶完成加冕并接管徐霄一行 → 熊大及多名关系人物被留作仙帝宫仆从。
6. 徐霄赠送十颗大罗鸿蒙丹 → 返还一千颗大罗鸿蒙丹，但未改变雪瑶拘禁决定。
7. 雪瑶松动束缚准备处置徐霄 → 混元破空盘被激活，徐霄脱困。
8. 第 822 章返回天水城与万妖仙宗 → 转入下界接人与天魁峰重新安置阶段。

## 主要人物与状态变化

- **徐霄：** 获得三十颗及一千颗大罗鸿蒙丹、天道神威绝金剑和混元大罗神冰符；从飘雪仙帝宫拘禁中脱困。
- **雪瑶／姬雪：** 完成仙帝加冕，公开接管徐霄及其关系网络；接受十颗大罗鸿蒙丹后仍坚持控制徐霄。
- **天翎：** 接受复合赠礼，与徐霄建立秘密关系。
- **天穹：** 被龙贞等万妖仙宗高层处置，确认死亡。
- **上官清：** 雪瑶核心亲信、万花仙宗临时掌门、SSS 级气运之女。
- **周紫薇：** 获得金仙巅峰冰符，首次羁绊暴击被使用。
- **熊大及仙帝宫侍女组：** 被雪瑶留下并分配长期仆从职责。
