# NODE-0107：初殷仙帝寿宴、至尊仙帝战力与三帝敌对

- **章节范围：** 第 854—863 章
- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

万妖仙宗抵达初殷四千万岁寿宴。徐霄以五十颗大罗鸿蒙丹压过各大仙帝贺礼，初殷被系统确认为 SSS+ 级气运之女；赠礼返还一颗鸿蒙一气丹和四千九百颗大罗鸿蒙丹。雪瑶到场后接受天道神威黑冰剑，系统返还神器诛仙天冰剑。

寿宴切磋中，徐霄以五柄顶级规则道器组成的五行剑阵秒杀至尊太乙修罗擎天。冥法随后公开问责并亲自出手，徐霄以五十股鸿蒙真气、混元神体和万佛金身正面对掌，将冥法击退。黑神、破玄、冥法同时被系统识别为仙帝级气运之敌；徐霄被直接判定为切磋第一名。第 864 章仙帝宫被传送入炼神鼎，剧情转入域外天修危机。

## 关键因果链

1. 初殷恢复年轻真容并被系统识别 → 徐霄以大罗鸿蒙丹建立仙帝级资源关系。
2. 雪瑶因凤青玄、初殷关系问责 → 天道神威黑冰剑赠送并返还神器诛仙天冰剑。
3. 三名外域仙帝被系统识别为气运之敌 → 徐霄主动参加寿宴切磋试探其计划。
4. 修罗擎天先行下杀手 → 徐霄以五行规则剑阵和弑神大道将其彻底击杀。
5. 冥法亲自出手 → 徐霄公开展示可压制普通仙帝的肉身与鸿蒙真气战力。
6. 三帝仍强行留席 → 域外天修计划继续推进，并在第 864 章触发炼神鼎危机。
