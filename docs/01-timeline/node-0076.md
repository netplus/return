# NODE-0076：做好事系统、云隐城与海底灵矿任务

## 剧情摘要

东方青在徐霄与罗素关系公开后持续执行“做好事”策略，试图借系统奖励提升修为。系统进一步确认东方青属于气运之子，绑定三级“做好事就变强系统”：完成善行获得积分，积分可兑换丹药，系统等级仍处于天道规则范围内。

徐霄随南宫嫣、莫问书和凌白烟前往云隐城处理南海海底灵矿争端。南宫嫣已晋升人仙巅峰；徐霄向其补充化仙丹和两张人仙九重寒冰符，分别返还仙元丹与地仙九重极道万冰符。徐霄同时服用此前获得的三千天道丹，完美领悟剑之大道。

云隐城方面由玄阴仙宗掌门厉红魅和城主南宫化极接待。众人确认灵矿年产约八百至一千枚上品灵精、预计可开采千年以上，而占矿的金蟾族分支已秘密投靠纯阳仙门。谈判中，纯阳仙门弟子要求柳清浅亲赴宗门与青锋洽谈。系统将青锋识别为气运之敌，发布击杀任务，并以额外传送仙台作为奖励，冲突由资源谈判正式升级为系统任务。

## 关键因果链

1. 东方青公开做好事 → 其三级系统规则和气运之子身份得到确认。
2. 南宫嫣道伤资源线推进 → 晋升人仙巅峰并获得持续丹药、符箓支持。
3. 金蟾族秘密投靠纯阳仙门 → 普通灵矿分配争端升级为两大仙门势力冲突。
4. 青锋借灵矿争端要求柳清浅赴约 → 系统识别其为气运之敌并发布击杀任务。
5. 额外传送仙台成为任务奖励 → 下一阶段转入灵矿夺取、青锋引出与击杀闭环。

## 主要人物与状态变化

- **徐霄：** 年龄一千零三十四岁、渡劫七重；服用三千天道丹后完美领悟剑之大道；进入灵矿任务并获得击杀青锋系统任务。
- **东方青：** 确认为气运之子；绑定三级做好事就变强系统，可用善行积分兑换丹药。
- **南宫嫣：** 晋升人仙巅峰；接受十颗化仙丹及两张神霄玄冰符，继续推进道伤修复资源线。
- **厉红魅：** 玄阴仙宗掌门、人仙七重、B级气运之女；作为云隐城一方核心负责人进入主线。
- **南宫化极：** 云隐城城主、人仙一重、南宫嫣祖父。
- **金大友：** 金蟾族分支族长、人仙九重，代表金蟾族拒绝让出灵矿。
- **青锋：** 纯阳仙门内门执事、地仙修士；因借灵矿争端谋求接触柳清浅，被系统识别为气运之敌。
