# NODE-0075：南宫嫣道伤、三千天道丹与太上长老认可

- **章节范围：** 第 573—580 章
- **粒度：** Story arc
- **核验状态：** `partial`

## 剧情摘要

南宫嫣因道伤与情绪波动出现灵力逆流和吐血症状。罗素出手稳定其修为，并进一步揭示这项旧伤的长期后果：若无额外机缘，南宫嫣需要在千年寿元窗口内晋升地仙，再以五行之气重塑三花，才能从根本上修复道基。

与此同时，徐霄与罗素的关系在阴阳仙门外门迅速公开。系统返还三千天道丹，确认该丹可使服用者完美领悟一条上位大道，并与三千大道丹共同构成随机出现的三千大道体系。徐霄还向看守府邸的莫问书、凌白烟赠送化仙丹作为答谢。

罗素父母万青、罗方以太上长老身份到达外门，最初将事件视为徐霄欺骗罗素感情并准备问责。罗素公开坚持关系，徐霄则通过长期资源承诺、十颗高品质仙元丹和一件顶级仙器证明实际投入。两位太上长老由质疑转为认可，并在外门长老团面前接受两人的公开关系。

东方青得知旧道侣罗素的新关系后，没有立即正面冲突，而是启动长期挽回策略。他计划利用自身“做好事获得成长”的系统机制提升修为，再重新争取罗素。第 581 章起，该策略转入公开执行阶段。

## 关键因果链

1. 南宫嫣道伤并发症恶化 → 晋升地仙并重塑三花成为明确的生存目标。
2. 徐霄与罗素关系公开 → 外门舆论与太上长老家族问责同时升级。
3. 高品质仙元丹与顶级仙器展示 → 万青、罗方由怀疑徐霄动机转为认可长期资源承诺。
4. 太上长老认可关系 → 徐霄资源网络进入阴阳仙门最高层之一。
5. 东方青确认罗素关系变化 → 掌门与亲传弟子的私人矛盾转为隐蔽长期竞争。
6. 第 581 章东方青开始主动执行做好事策略 → 进入下一剧情阶段。

## 主要人物与状态变化

- **徐霄：** 获得三千天道丹；通过仙元丹和顶级仙器取得万青罗方认可；资源网络进入太上长老层级。
- **南宫嫣：** 道伤并发症公开恶化；根治路径明确为晋升地仙后以五行之气重塑三花。
- **罗素：** 与徐霄关系由私人关系转为父母和外门长老团公开认可。
- **万青：** 阴阳仙门太上长老、罗素之母；由问责转为支持两人关系。
- **罗方：** 阴阳仙门太上长老、罗素之父；由保护性制止转为接受关系。
- **东方青：** 境界确认为天仙一重；启动借做好事系统提升修为并挽回罗素的策略。
- **莫问书、凌白烟：** 为徐霄罗素看守府邸后各获三枚化仙丹。
