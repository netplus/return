# NODE-0092：凤族血令、天凤血丹与火蜥冲突

## 剧情摘要

凤青玄从万妖仙宗返回天水城，将师父天翎长老的凤族血令交给徐霄。血令以天凤血脉炼成，可压制普通妖族血脉并代表金仙长老的庇护。徐霄向凤青玄赠送十颗仙元丹，获得一百颗五行仙丹返还。

灵田中六名九阴玄门修士因无法承受长期灵力压榨而逃跑，被万魂盘神魂烙印击落。徐霄以十颗天凤血丹换取玄雪暂缓处决，其中首颗触发鸿蒙一气丹，余九颗返还二十七颗高品天凤血丹。玄雪确认血丹可提升玄鸟一族的天凤血脉，并进一步确认徐霄持有天凤血令。

火蜥蜴族公子蜥风依据北鳞许可，强迫焰灵成为妾室。系统将其识别为气运之敌并发布击杀任务。徐霄以大道玄冰剑瞬杀蜥风及五名火蜥族随从，完成任务，使丹药返还库上限提升至金仙。随后徐霄以凤族血令压下巡视妖族追责，并向焰灵赠送十颗仙元丹，返还五十颗五行仙丹，完成焰灵的关系与资源安置。

## 关键因果链

1. 凤青玄取得天翎长老信物 → 徐霄获得天凤族金仙层级政治保护。
2. 玄雪接受天凤血丹并确认血脉提升 → 玄鸟族对徐霄由敌视转为资源依赖和谨慎合作。
3. 北鳞许可火蜥族强迫焰灵 → 蜥风成为系统气运之敌。
4. 徐霄击杀蜥风及随从 → 丹药返还库上限升级至金仙。
5. 凤族血令压制巡视妖族追责 → 蜥风冲突在天水城现场暂时收束。
6. 第 698 章八大妖族集体逼宫 → 进入新的跨族政治冲突阶段。
