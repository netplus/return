# NODE-0093：八族逼宫、天翎血凤与天水城反转

- **章节范围：** 第 698—705 章
- **粒度：** Story arc
- **核验状态：** `partial`

## 剧情摘要

蜥风被杀后，天水城八大妖族集体向城主府施压，要求处置徐霄。天翎通过凤族血令明确介入：一方面要求徐霄暂时与凤青玄分开，另一方面承诺以天凤族金仙长老身份处理蜥风事件。凤青玄对此强烈不满，但徐霄选择暂时服从以换取现实庇护。

逼宫现场，徐霄反向追责火蜥族，并被系统告知蜥雷是气运之敌、蜥红蝶是 C 级气运之女。赤澜儿最初迫于八族压力准备将徐霄关押，随后天翎以灵气血凤分身降临并公开为徐霄撑腰，天水城三名仙宗执事及八大妖族立场迅速逆转。灵藏人族的灵植上缴任务被削减，徐霄由被征服修士进一步转为天水城实际不可轻易触碰的特殊人物。

五年后，玄鸟族在徐霄的战略安排下伏击火蜥族精锐，蜥雷、蜥红蝶及同行火蜥族修士死亡。系统结算蜥雷气运之敌任务，并对蜥红蝶死亡给出特殊补偿；精确奖励拆分仍待完整正文复核。徐霄服用祖凤天血丹，修为升至天仙三重，天凤血脉进化为祖凤血脉，并获得造化涅槃重生能力。

## 关键因果链

1. 蜥风死亡 → 八大妖族集体逼宫并要求处置徐霄。
2. 天翎通过凤族血令介入 → 徐霄以暂时分手换取天凤族金仙层级公开庇护。
3. 天翎灵气血凤分身降临 → 城主府与八大妖族由问罪转为退让。
4. 天水城权力反转 → 灵藏人族灵植任务减半，徐霄获得更高行动自由。
5. 玄鸟族伏击火蜥族 → 蜥雷任务与蜥红蝶特殊补偿进入系统结算。
6. 祖凤天血丹服用 → 徐霄晋升天仙三重并获得祖凤血脉与涅槃重生能力。
7. 第 706 章转入人族养伤小队与边境战事，因此进入下一节点。

## 主要人物与状态变化

- **徐霄：** 晋升天仙三重；年龄 1055 岁；鸿蒙真气 61 股；天凤血脉进化为祖凤血脉；获得造化涅槃重生能力。
- **凤青玄：** 因天翎命令与徐霄暂时分开，对徐霄迅速同意分手强烈不满。
- **天翎：** 以万妖仙宗天凤族金仙长老身份公开介入天水城事务，并以灵气血凤分身保护徐霄。
- **焰灵：** 与徐霄羁绊度提升至 2，获得地仙巅峰大道神丹和持续资源承诺。
- **蜥雷：** 火蜥族族长、气运之敌；第 704—705 章阶段被玄鸟族伏击清除。
- **蜥红蝶：** 火蜥族玄仙、C 级气运之女；与蜥雷一同死亡，引发系统特殊补偿。
- **玄灵：** 玄鸟族老祖，玄仙六重；带领玄鸟族伏击火蜥族精锐。
- **赤澜儿、铁煞天、北鳞：** 在天翎介入后由处置徐霄转为公开示好和保护。
