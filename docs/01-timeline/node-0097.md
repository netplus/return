# NODE-0097：万妖仙宗抵达、公开问责与入门选拔

- **章节范围：** 第 729—736 章
- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

徐霄、金虚、玄灵、玄雪等战功修士抵达万妖仙宗。诸葛青天燃烧寿元将修为推至玄仙六重，并与独孤惊云共同摆脱万魂盘烙印；独孤惊云依靠天穹长老引荐进入选拔。天翎当众收回凤族血令，在徐霄识海留下天凤金光并要求其结束现有关系；赤狐族老祖赤裳随后准备直接处置徐霄，但在接受超绝品质金仙道丹后停止行动，系统由此返还道气玄天丹。

入门选拔以照妖宝镜和神通法器测试为核心。独孤惊云凭道天仙体成为天穹亲传，诸葛青天成为普通弟子；玄灵、玄雪显现金色仙体天赋并进入天翎麾下。徐霄的太初仙体呈现最强金光，却因人妖两族的负面名声无人愿收。第二轮中，他以六颗巨型金仙道丹建立与新晋金仙长老熊大的资源合作，取得首席执事身份，并推动青曼、雀鸢、雪小星同获天魁峰执事席位。徐霄入驻天魁峰后服用道气玄天丹，五脏五行之气凝成玄仙道气，突破玄仙不再存在瓶颈；雪小星接受复合资源并与其确立关系。

## 关键因果链

1. 青木城战功结算完成 → 徐霄一行抵达万妖仙宗参与入门选拔。
2. 诸葛青天继续燃烧寿元 → 修为升至玄仙六重，但剩余寿元仅一万年。
3. 天翎、赤裳公开问责 → 徐霄在万妖仙宗的负面舆论转化为直接身份阻力。
4. 赤裳接受金仙道丹 → 系统返还道气玄天丹，公开处置暂时停止。
5. 照妖宝镜确认太初仙体 → 徐霄天赋最高，但仍因声誉被金仙长老集体拒绝。
6. 徐霄以六颗金仙道丹建立熊大合作 → 获得首席执事身份，并为三名关系人物取得执事席位。
7. 道气玄天丹被服用 → 徐霄形成玄仙道气并解除玄仙突破瓶颈。
8. 第 737 章发生三年时间跳跃 → 转入天魁峰扩张、返还库升级与天翎再次问责阶段。

## 主要人物与状态变化

- **徐霄：** 加入万妖仙宗天魁峰并成为熊大首席执事；太初仙体获照妖宝镜确认；服用道气玄天丹后形成玄仙道气；与雪小星确立关系。
- **诸葛青天：** 修为升至玄仙六重，寿元降至一万年；加入天穹麾下成为普通弟子。
- **独孤惊云：** 道天仙体被确认，成为天穹亲传弟子，并与诸葛青天共同摆脱万魂盘烙印。
- **天翎：** 收回凤族血令，在徐霄识海植入天凤金光；收玄灵为执事、玄雪为弟子。
- **赤裳：** 赤狐族至尊金仙老祖、SSS 级气运之女；接受金仙道丹后暂缓处置徐霄。
- **熊大：** 金仙一重的新晋长老；以天魁峰首席执事身份接纳徐霄，并将三个执事席位交给其关系人物。
- **雪小星：** 雪兔族族长、A 级气运之女；成为天魁峰执事并与徐霄确立关系。
- **金虚、玄灵、玄雪、青曼、雀鸢、韵幽：** 分别完成万妖仙宗长老麾下的执事或弟子身份落位。
