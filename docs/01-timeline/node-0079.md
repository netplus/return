# NODE-0079：柳清浅入地仙、集体晋升内门与刘爱花会面

- **章节范围：** 第 604—609 章
- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

东方青支持徐霄后，厉红魅获准筹备进入阴阳仙门。内门传功长老陆道离为厉红魅六十二万岁生日准备九凤金钗，并暴露其亲传弟子“张大全”正是以道元身份活动的天元界飞升者；张大全因凤青玄飞升而持续隐藏身份。

柳清浅闭关突破地仙，接受徐霄十颗仙元丹并返还三十颗五行仙丹。两人形成对外保密的关系与长期资源承诺。柳清浅随后拜入地仙巅峰传功长老绝柔门下；徐霄、莫问书、凌白烟、罗素、梦琳和云姑心同时进入内门。莫问书、凌白烟、梦琳、云姑心进入执法堂，罗素恢复内门传功长老身份，徐霄在东方青担保下直接成为内门执法执事。

徐霄拜访凤青玄，赠送十颗化仙丹，返还一百颗仙元丹；凤青玄允许其改称“青玄”，双方资源关系继续加深。随后徐霄拜访以“刘爱花”身份生活的姬雪，系统直接确认其真实身份。徐霄不揭穿，向刘爱花赠送十颗化仙丹并返还一百颗仙元丹；姬雪决定继续利用刘爱花身份接受资源。徐霄修为升至渡劫八重，并接受孟凡邀请，准备参加阴阳飞升会。

## 关键因果链

1. 柳清浅晋升地仙 → 获得进入内门和拜入绝柔门下的资格。
2. 外门高层与优秀弟子集体晋升 → 徐霄资源网络正式转入内门。
3. 东方青公开担保 → 徐霄跳过普通执法弟子阶段，直接成为内门执法执事。
4. 凤青玄接受化仙丹 → 双方称呼与资源关系进一步亲近。
5. 系统识别刘爱花为姬雪 → 徐霄选择不揭穿，以维持稳定赠送与返还渠道。
6. 孟凡邀请徐霄加入飞升会 → 道元/张大全和下界飞升者关系线成为下一阶段主线。

## 主要人物与状态变化

- **徐霄：** 晋升渡劫八重；成为阴阳仙门内门执法执事；与柳清浅形成保密关系；识破刘爱花即姬雪但暂不揭穿。
- **柳清浅：** 晋升地仙；拜入绝柔门下成为亲传弟子；接受十颗仙元丹并获得长期资源承诺。
- **凤青玄：** 接受十颗化仙丹；允许徐霄改称“青玄”，并获得后续仙剑承诺。
- **姬雪：** 刘爱花伪装被系统识别；接受十颗化仙丹，并计划以刘爱花身份持续获得资源。
- **罗素：** 返回内门并恢复传功长老身份；再次接受十颗仙元丹。
- **莫问书、凌白烟、梦琳、云姑心：** 集体进入内门执法堂。
- **陆道离：** 内门传功长老、张大全之师，准备借厉红魅生日挽回关系。
- **孟凡：** 十万年前由青云仙宗飞升，邀请徐霄参加阴阳飞升会。
