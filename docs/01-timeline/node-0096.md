- **核验状态：** `verified`

## 剧情摘要

徐霄在青木城战后继续结交气运对象，系统结算仙丹赠送，新增鸿蒙一气丹与金仙道丹。两个月后，妖族在前线取得决定性优势，人妖双方进入最终谈判。徐霄向凤天晴配置高阶丹药，缓和其对自身关系网络的公开问责；又与火雀族族长雀鸢确立关系，赠送九霄山河图、魂丹与仙丹，返还大道山河图、金仙巅峰魂丹及修炼资源。

徐霄服用鸿蒙一气丹后鸿蒙真气增至六十六股，并服用三千天道丹完美领悟阵之大道。最终谈判中，他拒绝返回人族阵营，以顶级至尊玄仙符箓形成威慑，迫使孔青及妖族代表暂时接受其继续留在妖族；人族代表苏破天、温晴岚则将其视为沟通两族的特殊桥梁。战后，玉龙、金虚等人解除俘虏身份并获推荐参加万妖仙宗选拔，徐霄因战功最大同样获得推荐与宗门贡献。

## 关键因果链

1. 青木城阵眼战取得阶段胜利 → 人妖战争进入最终谈判。
2. 凤天晴获得高阶资源 → 对徐霄的公开问责转为现实妥协。
3. 雀鸢接受复合赠礼 → 徐霄获得大道山河图、金仙巅峰魂丹和新增修炼资源。
4. 三千天道丹被服用 → 徐霄完美领悟阵之大道，阵法能力形成长期跃迁。
5. 徐霄拒绝回归人族并展示保命符箓 → 人妖双方均放弃强制处置。
6. 战功结算完成 → 灵藏人族与多名妖族修士获得万妖仙宗选拔入口。
7. 第 729 章抵达万妖仙宗 → 进入宗门选拔与天翎问责新阶段。

- **凤天晴：** 接受高阶丹药后，由强硬问责转为务实约束与战功认可。
