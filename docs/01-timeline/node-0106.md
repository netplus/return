- **粒度：** Story arc

## 剧情摘要

万妖仙宗高层集体护送徐霄前往轩辕仙城接亲。六大上宗汇聚阻拦，徐霄以规则道器击杀魔无天，完成气运任务并获得混元破界九霄天梯；随后与轩辕婉君正式完婚。十五年间，徐霄晋升太乙仙，扩充鸿蒙真气、规则道器和神器储备，并与狐嫣、天翎等关系公开化。

凤青玄以天羽身份出关后要求恢复唯一道侣关系，雪瑶则公开承认自己就是刘爱花。两名仙帝级强者发生神魂大战，徐霄暂时选择雪瑶，继而进入天凤峰以祖凤血丹、大罗鸿蒙丹和规则道器安抚凤青玄。凤青玄与徐霄复合并公开关系，获得大罗巅峰大道神丹，准备在初殷寿宴挑战仙帝之位。

## 关键因果链

1. 轩辕接亲遭六宗阻拦 → 魔无天被击杀，跨界神器奖励落地。
2. 轩辕家高层接受资源 → 轩辕婉君婚事正式完成。
3. 十五年资源循环与自动修炼 → 徐霄晋升太乙二重、鸿蒙真气增至九十一股。
4. 凤青玄出关与雪瑶到场 → 两名仙帝级强者公开争夺徐霄。
5. 徐霄暂选雪瑶后再安抚凤青玄 → 凤青玄接受复合赠礼并恢复公开道侣关系。
6. 初殷寿宴临近 → 万妖仙宗携凤青玄与徐霄前往仙帝宫。

## 主要人物与状态变化

- **徐霄：** 太乙仙二重，1080 岁，剩余寿命 30,010,229 年，鸿蒙真气九十一股；获得混元破界九霄天梯、天地双神环和诛仙神火剑。
- **轩辕婉君：** 道伤修复后晋升太乙仙，与徐霄正式完婚，羁绊度二。
- **魔无天：** 肉身与神魂俱灭。
- **魔无花：** 获魔罗圣门大罗仙认可，成为新掌门。
- **凤青玄：** 以天羽身份回归，达到大罗仙级准仙帝战力；与雪瑶大战后和徐霄复合，准备挑战初殷。
- **天翎：** 与徐霄公开成婚，并转为凤青玄座下弟子。
