# NODE-0101：云花海安置、轩辕仙城会盟与太初第一圣子上位

- **章节范围：** 第 763—772 章
- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

云花海为五灵仙门门人解除俘虏身份来到天魁峰求助，徐霄承诺协调天翎并提供长期资源。云花海接受复合赠礼后迁入万妖仙宗，赤澜儿与玄雪的聘礼和安置也相继落地。徐霄晋升玄仙三重，鸿蒙真气增至七十三股，并通过玄灵、天翎和凤溪进一步稳固天凤族政治关系。

万妖仙宗随后赴轩辕仙城参加轩辕婉君与血无涯的订婚仪式。六大顶级仙宗齐聚，魔无天与血无涯先后被系统识别为气运之子。围绕“太初仙域第一圣子”的公开争论中，徐霄展示五行道器剑阵、完美噬神大道和至尊金仙级战力，击杀主动偷袭的噬魂血宗金仙长老，迫使血无涯退出名号争夺，完成公开上位。

## 关键因果链

1. 五灵仙门仍受俘虏身份约束 → 云花海拜访天魁峰寻求安置。
2. 复合赠礼与宗门身份安排 → 云花海迁入万妖仙宗并成为熊大弟子。
3. 赤狐族与天凤峰接受聘礼 → 赤澜儿、玄雪关系和居所正式落地。
4. 凤溪接受太乙聚仙丹 → 天凤族高层承诺压制宗门反徐舆论。
5. 六大仙宗齐聚轩辕仙城 → 徐霄获得公开比较顶级圣子的舞台。
6. 噬魂血宗金仙长老偷袭 → 徐霄公开展示道器和噬神大道并完成反杀。
7. 血无涯退出名号争夺 → 徐霄取得太初仙域第一圣子的公开名号。
8. 第 773 章拍卖会开始 → 转入资源竞拍与轩辕婉君治疗新阶段。

- **云花海：** 接受复合赠礼并迁入万妖仙宗，成为熊大弟子。

- **玄灵：** 羁绊度提升至二，并获得祖凤血丹、道器和高阶符箓等资源。

- **熊大：** 在六宗会盟中公开推举徐霄为第一圣子。
