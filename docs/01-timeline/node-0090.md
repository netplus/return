- **粒度：** Story arc

## 剧情摘要

诸葛青天再次以寿元换取系统力量，将修为恢复到天仙巅峰并获得三柄至尊仙器，但寿元仅余四十万年。随后大仙域局势突变：太初仙域妖族攻占十八座人族仙城，天水城失守，掌控跨域传送的金虚率先投降。铁煞天、北鳞、赤澜儿三名天地玄仙妖修进入灵藏仙域，迫使七大仙门接受妖族统治并准备将地仙以上修士带往大仙域。

阴阳仙门获知噩耗后，全宗陷入震动。徐霄判断妖族承诺不足以保障核心关系网络安全，遂以九霄山河图、九霄天梯和传送仙台，将李香香、韩烟、陈玉、罗素、厉红魅、南宫嫣、云姑心、凌白烟、邬秋、丁静、梦琳转移至天元大陆盘龙岛缥缈宗，并承诺持续跨界供应资源。灵藏沦陷由外部情报转为持续生存危机，徐霄的资源网络首次承担跨界避难基础设施功能。

## 关键因果链

1. 妖族攻陷太初仙域十八城、天水城失守 → 灵藏仙域跨域出口与上级人族支援体系崩溃。
2. 金虚投降并引导三名天地玄仙妖修进入灵藏 → 七大仙门失去军事与政治自主权。
3. 妖族要求地仙以上修士前往大仙域 → 阴阳仙门高层和核心人物面临被征调、控制及充当妖族附庸的风险。
4. 徐霄不信任妖族长期承诺 → 将核心气运之女群体转移至盘龙岛。
5. 传送仙台留置盘龙岛并定期输送资源 → 下界从临时退路升级为长期安全后方。
6. 第 681 章转入青鸾妖身及妖族身份谈判 → 进入下一剧情阶段。

## 主要人物与状态变化

- **徐霄：** 建立盘龙岛跨界避难与资源供应体系，保护十一名核心关系人物。
- **诸葛青天：** 再次燃烧寿元，恢复天仙巅峰并持有六件至尊仙器，寿元降至四十万年。
- **凤青玄：** 境界达到地仙二重，与徐霄关系进一步确认，并获得仙元丹资源。
- **姬雪／刘爱花：** 接受仙元丹并继续以刘爱花身份维持资源关系。
- **金虚：** 天水城及灵藏跨域传送话事人；投降妖族并推动灵藏仙域臣服。
- **铁煞天、北鳞、赤澜儿：** 三名进入灵藏仙域的天地玄仙妖族使者，成为实际占领权力核心。
