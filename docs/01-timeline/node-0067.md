- **章节范围：** 第 509—516 章
- **粒度：** Story arc
- **核验状态：** `partial`

## 剧情摘要

天山试炼即将结束时，蓬莱仙宗阴灵阵营完成九处阵眼并启动幽冥天绝阵。渡劫九重级阵法封锁九耀天山副山，持续抽取阵内修士灵力。系统同时确认，抽取、剥离类诅咒恶术造成的损失可以直接返还，而且不受气运之女对象限制；道元圣体又能把侵入体内的幽冥阴气炼化为灵力。徐霄因此没有立即破阵，而是利用阵法快速修炼。

援军神天以渡劫六重修为入阵后迅速被阴灵夺舍，现场修士将其视为陨落。随后八名渡劫阴灵同时进入徐霄识海，却被仙神魂胎全部击溃并吸收。阵法返还、圣体炼化与神魂吞噬叠加后，徐霄由大乘三重提升至大乘七重。

徐霄祭出九幽惊魂剑，大规模清剿阴灵并驱逐多名修士识海中的夺舍者。葬花、北风以渡劫八重级阴灵形态迎战，仍被仙剑压制并收入山河灵图。系统最终确认海岚、葬花、北风三名气运之敌死亡，法器、丹药、符箓阵法三类返还库上限分别升级至至尊仙器、地仙境和人仙境。

凯旋后，徐霄被十八上宗视为天元大陆救世主和第一天修。他推动各宗立即肃清蓬莱仙宗残余阴灵、查找并关闭两界裂缝。第 516 章完成战后关系和资源安排，系统返还九天神玉带；原始受赠对象和逐笔映射仍待补证。神玉随后安排素青陪同徐霄进入秘境仙池休整，第 517 章转入系统升级、修为再进与飞升准备。

## 关键因果链

1. 九处阵眼完成 → 海岚启动幽冥天绝阵并抽取全场灵力。
2. 系统返还抽取损失 + 道元圣体炼化阴气 → 徐霄反向利用阵法修炼。
3. 神天被快速夺舍 → 天元大陆强者确认阴灵威胁已达到渡劫高阶层级。
4. 八名渡劫阴灵进入徐霄识海 → 仙神魂胎将其击溃吸收，徐霄升至大乘七重。
5. 九幽惊魂剑群体清剿 + 山河灵图收纳 → 阴灵主力和葬花、北风被快速清除。
6. 海岚、葬花、北风任务结算 → 三类返还库上限全面升级。
7. 徐霄成为第一天修 → 十八上宗由试炼竞争转入跨宗肃清和裂缝封闭行动。
8. 第 516 章战后赠礼返还 → 九天神玉带入库并衔接仙池休整；第 517 章开启新阶段。
