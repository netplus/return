## 剧情摘要

金石城冲突结束后，系统识别玄魔宗掌门李天霸为新的气运之敌，并发布击杀任务，奖励为“下一次有效赠送必定触发万倍暴击”。李天霸得知李九夜及宗门精锐死亡后，率玄魔宗主力准备报复金石城。徐霄主动拦截并表明身份，随后使用九天神雷符将玄魔宗主力和山门一并摧毁，任务随之完成。

回到缥缈宗后，徐霄向金柳香补充筑基丹、上品灵石和元婴地火符。任务奖励作用于筑基丹赠送，万倍暴击返还天地神丹九转乾元丹；其余资源按当时基础倍率返还。徐霄服用九转乾元丹后被重塑为道体，修炼速度和气运显著提升，境界很快进入结丹期并达到结丹二重。

玄魔宗覆灭开始影响正魔两道。合欢宗掌门玉玲珑首次登场并关注徐霄及事件后果。独孤灵到访后，徐霄将九天神凤钗赠予她，系统返还法宝须臾五极山。至第 38 章，玄魔宗覆灭、任务奖励、道体重塑、独孤灵赠礼和宗门舆论形成阶段闭环；第 39 章转入魔道势力正式上门。

## 关键因果链

1. 李九夜及玄魔宗精锐死亡，使李天霸准备报复金石城。
2. 系统将李天霸识别为气运之敌，并发布击杀任务。
3. 徐霄主动承担后果并使用九天神雷符覆灭玄魔宗。
4. 任务完成后，下一次有效赠送获得必定万倍暴击。
5. 徐霄向金柳香赠送十枚筑基丹，返还九转乾元丹。
6. 九转乾元丹重塑徐霄体质，使其进入快速恢复修为阶段。
7. 玄魔宗覆灭引发正道宗门和魔道附属关系的连锁反应。
8. 徐霄将九天神凤钗赠予独孤灵，返还须臾五极山。

## 主要状态变化

- 徐霄：筑基五重恢复至结丹二重；九转乾元丹将其体质重塑为道体。
- 李天霸：玄魔宗掌门、李九夜之父、气运之敌；死于九天神雷符。
- 玄魔宗：山门和主要成员被摧毁，作为稳定势力退出当前格局。
- 金柳香：修为达到筑基五重；继续接受徐霄提供的修炼和护身资源。
- 独孤灵：获得绝品法器九天神凤钗。
- 玉玲珑：合欢宗掌门首次登场，开始关注徐霄和玄魔宗覆灭事件。

## 系统与物品增量

- 新任务机制：系统可识别“气运之敌”，发布击杀任务，并将奖励绑定到下一次赠送。
- 任务奖励：击杀李天霸后，下一次有效赠送必定触发万倍暴击。
- `GIFT-0011`：
  - 十枚筑基丹 → 万倍暴击 → 九转乾元丹。
  - 十枚上品灵石 → 二十倍返还 → 二百枚上品灵石。
  - 元婴地火符 → 二十倍返还 → 两张化神九重赤炎火符。
- `GIFT-0012`：九天神凤钗赠予独孤灵 → 返还须臾五极山。
- 九天神雷符：在本节点中消耗，用于覆灭玄魔宗。
- 九转乾元丹：天地神丹，重塑体质和气运，并显著提升修炼速度。
- 须臾五极山：可大可小、坚如金铁，并具有极强镇压重量的法宝。
