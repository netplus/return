# NODE-0105：返回万妖仙宗、天魁峰安置与孔玄处置

- **章节范围：** 第 822—830 章
- **粒度：** Story arc
- **核验状态：** `verified`

## 剧情摘要

徐霄从飘雪仙帝宫脱困后先返回灵藏仙域，随后将尘玉、东方青、邹蒙和莫问书带入万妖仙宗，并为四人落实执事身份和天魁峰居所。尘玉接受复合高阶资源后与徐霄确立关系；龙贞等六名宗门高层接受资源委托，安排处置孔玄。

凤青玄完成历代天凤圣女涅槃融合，继承天羽身份、三十二代圣女记忆和二十三股鸿蒙真气，并以分魂下界进入盘龙岛，取得天地灵根类规则道器及五道无主鸿蒙真气。万妖仙宗方面，蝎晴被识别为 SS 级气运之女，接受金仙道丹和大道玄冰剑后与徐霄确立关系；魔无花获得太乙聚仙丹及重返魔罗圣门的长期承诺。孔玄最终被宗门高层间接击杀，法器返还库上限提升至神器。

## 关键因果链

1. 徐霄返回灵藏仙域 → 尘玉等四人进入万妖仙宗并获得执事身份。
2. 尘玉接受复合赠礼 → 获得长期资源保障并与徐霄确立关系。
3. 六名高层接受太乙聚仙丹委托 → 孔玄被安排外出并最终遭处置。
4. 凤青玄完成天羽涅槃融合 → 继承历代记忆、修为与鸿蒙真气，并下界夺取规则道器机缘。
5. 蝎晴被系统识别并接受赠礼 → 徐霄获得鸿蒙一气丹、太乙聚仙丹和天道神威黑冰剑。
6. 孔玄死亡完成任务 → 法器返还库上限提升至神器。
7. 第 831 章转入轩辕仙城接亲 → 开启新的跨宗门冲突阶段。

- **徐霄：** 晋升金仙二重；鸿蒙真气增至八十一股；完成孔玄任务并将法器返还库提升至神器。
- **尘玉：** 晋升万妖仙宗执事，迁入天魁峰并与徐霄确立关系。
- **蝎晴：** 天毒蝎族金仙六重老祖、SS 级气运之女；成为徐霄助手并与其确立关系。
- **魔无花：** 获得长期太乙聚仙丹支持及重返魔罗圣门的承诺。
- **孔玄：** 被龙贞等宗门高层处置，人物死亡。
- **凤青玄／天羽：** 完成历代圣女融合，继承二十三股鸿蒙真气并取得盘龙岛规则道器与五道无主鸿蒙真气。
- **东方青、邹蒙、莫问书：** 获得万妖仙宗执事身份并成为天魁峰府邸管理人员。
